## 빅데이터의 영향과 활용 가치

### 주체별 영향

| 주체 | 영향 |
|---|---|
| **기업** | 소비자 행동 분석, 시장 예측, 비즈니스 모델 혁신 |
| **정부** | 데이터 기반 정책 수립, 위기 대응, 공공 효율성 제고 |
| **개인** | 맞춤형 서비스 소비, 스마트 라이프 구현 |

### 빅데이터가 가치를 창출하는 5가지 방식

1. **투명성 제고**: 데이터 인프라 개방으로 효율성 극대화
2. **시뮬레이션**: 복잡한 변수 탐색으로 정확한 수요 포착
3. **고객 세분화**: 개인화된 맞춤 서비스 제공
4. **의사결정 자동화**: 알고리즘 기반 의사결정 보조·대체
5. **비즈니스 모델 혁신**: 데이터 융합으로 새로운 비즈니스 창출

### 주체별 영향 — 교재 표현 ⭐

| 주체 | 영향 |
|---|---|
| 기업 | **혁신**, **경쟁력 강화**, **생산성 향상** |
| 정부 | **환경 탐색**, **상황 분석**, **미래 대응** |
| 개인 | 목적에 따라 활용 — 맞춤형 서비스, 기회비용 절약 |

## 빅데이터 가치 산정의 어려움

| 어려움 요인 | 설명 |
|---|---|
| **데이터 재조합** | 다양한 방식의 재사용으로 누가 언제 어떻게 쓰는지 불명확 |
| **새로운 가치 창출** | 기존에 없던 가치 형태로 산정이 어려움 |
| **기술 발전의 역설** | 오늘 가치 없는 데이터가 내일 AI 학습용으로 가치 있을 수 있음 |

> **시험 표현**: 가치 산정이 어려운 이유 = ① 데이터 활용 방식(재사용·재조합·다목적 개발) ② 새로운 가치 창출 ③ 분석 기술의 발전

## 비즈니스 모델 — 활용 사례

| 주체 | 사례 |
|---|---|
| 기업 | 구글: 사용자 로그로 검색 품질 개선 / 월마트: 구매 패턴 분석으로 진열·판촉 최적화 |
| 정부 | 실시간 교통 정보, 기후·재난 정보 분석, 국가 안전 확보 |
| 개인 | 정치인의 소셜 미디어 분석 기반 선거 전략, 가수의 팬 반응 분석 기반 공연 기획 |

## 빅데이터 활용 기술 (7가지 테크닉)

| 테크닉 | 개념 | 실무 예시 |
|---|---|---|
| **1. 연관 규칙 학습** | 데이터 간 상관관계 발견 (장바구니 분석) | 맥주 구매자가 기저귀도 함께 구매 |
| **2. 유형 분석** | 데이터 분류 및 그룹화 | 고객을 고위험/저위험군으로 분류 |
| **3. 유전 알고리즘** | 진화 메커니즘으로 최적해 도출 | 서버 자원 배치 최적화 |
| **4. 기계학습** | 데이터로부터 규칙 자동 학습 | 음악/상품 추천 시스템 |
| **5. 회귀분석** | 원인(독립변수)이 결과(종속변수)에 미치는 영향 분석 | 나이·소득이 구매액에 미치는 영향 |
| **6. 감정분석** | 텍스트의 긍정·부정 감정 판별 | SNS 리뷰로 제품 평판 파악 |
| **7. SNS 분석** | 네트워크 구조에서 영향력 분석 | 인플루언서의 정보 확산력 측정 |

### 기법별 대표 질문 ⭐ (출제 형식)

| 기법 | 이런 질문에 답한다 |
|---|---|
| 연관 규칙 학습 | 커피를 사는 사람이 탄산음료도 많이 사는가? |
| 유형 분석 | 이 사용자는 어떤 특성을 가진 집단에 속하는가? |
| 유전 알고리즘 | 최대 시청률을 얻으려면 어떤 프로그램을 언제 방송해야 하는가? |
| 기계 학습 | 기존 시청 기록으로 볼 때 어떤 영화를 가장 보고 싶어 할까? |
| 회귀 분석 | 구매자의 나이가 구매 차량 종류에 어떤 영향을 미치는가? |
| 감정 분석 | 새 환불 정책에 대한 고객 평가는 어떤가? |
| 소셜 네트워크 분석 | 고객들 사이의 관계와 영향력 있는 사람은 누구인가? |

> 키워드: "함께 구매" → 연관, "어느 집단" → 유형, "최적화·배치" → 유전, "예측·추천" → 기계학습, "영향" → 회귀, "평판·의견" → 감정, "관계·영향력" → 소셜 네트워크

### 텍스트 마이닝 핵심 용어

| 용어 | 정의 |
|---|---|
| **토큰화** | 문장을 단어·형태소 등 최소 단위(토큰)로 분리 |
| **스태밍** | 단어의 원형(어간)을 추출 (가겠다, 갈 것이다 → 가다) |
| **코퍼스** | 분석 대상이 되는 대량의 텍스트 데이터 집합 |
| **임베딩** | 단어·문장을 고차원 숫자 배열(벡터)로 변환 |
