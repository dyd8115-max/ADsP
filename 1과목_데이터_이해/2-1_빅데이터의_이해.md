# 빅데이터의 이해

> 1과목 데이터 이해 › 2장 데이터의 가치와 미래

---

## 빅데이터의 정의

**빅데이터**: 기존 도구로 수집·저장·관리·분석이 어려운 대량의 정형/반정형/비정형 데이터와 이를 처리하는 기술·프로세스·인력을 포괄하는 개념

---

## 빅데이터의 특징

### 3V (기본 특징)

| 특징 | 설명 |
|---|---|
| **Volume (규모)** | 데이터의 양이 매우 큼 (TB, PB 단위 이상) |
| **Velocity (속도)** | 데이터가 생성·유통되는 속도가 빠름 (실시간 처리 요구) |
| **Variety (다양성)** | 정형·반정형·비정형 등 다양한 형태의 데이터가 혼재 |

### 4V (확장 버전)

3V에 다음 중 하나 또는 둘 다 추가:

| 특징 | 설명 |
|---|---|
| **Veracity (정확성)** | 데이터의 신뢰성·정확성 — 품질 보장 필수 |
| **Value (가치)** | 실제 비즈니스 가치 창출 가능성 |

> **참고**: 일부 학자는 여기에 **Visualization(시각화)**, **Variability(가변성)** 를 추가하는 견해도 있음
> - Visualization: 분석 결과를 효과적으로 시각화하는 능력
> - Variability: 데이터의 변동성·불안정성 관리

## 빅데이터 정의의 범위 ⭐

| 범위 | 관점 | 내용 |
|---|---|---|
| 좁은 범위 | 데이터 변화 | 규모·형태·속도 등 **데이터 자체의 특성** 변화 (3V) |
| 중간 범위 | 기술 변화 | 데이터를 처리·저장·분석하는 **새로운 기술과 아키텍처** |
| 넓은 범위 | 인재·조직 변화 | 데이터 사이언티스트 같은 **인재와 데이터 중심 조직**까지 포함 |

### 기관별 정의

| 기관 | 정의 |
|---|---|
| 가트너 | 3V(규모·속도·다양성) 특징을 갖는 정보 자산 |
| 맥킨지 (2011) | 일반적인 데이터베이스 소프트웨어로 **저장·관리·분석할 수 있는 범위를 초과**하는 규모의 데이터 |
| IDC (2011) | 다양한 종류의 대규모 데이터로부터 **저렴한 비용으로 가치를 추출**하고, 빠른 수집·발굴·분석을 지원하도록 고안된 **차세대 기술 및 아키텍처** |

## 빅데이터의 비유 (시대적 가치)
| 비유 | 의미 | 사례 |
|---|---|---|
| **산업혁명의 석탄·철** | 제조업뿐 아니라 **서비스 분야의 생산성**을 획기적으로 끌어올려<br>사회·경제·문화 전반에 혁명적 변화를 가져옴 | — |
| **21세기의 원유** | 경제 성장에 필요한 정보를 제공하여<br>**산업 전반의 생산성 향상 및 신산업 창출** | — |
| **렌즈 (현미경)** | 현미경이 생물학 발전에 미친 영향처럼,<br>**현상을 관찰하고 측정하는 도구**로서 산업 발전에 기여 | **구글 Ngram Viewer**<br>(도서 단어 빈도로 문화 변화 관찰) |
| **플랫폼** | 공동 활용 목적으로 구축된 **기반 구조**<br>다양한 **서드파티 비즈니스**가 그 위에서 성장 | **페이스북, 카카오톡**<br>(API 공개로 타 서비스가 활용) |

> **구분 포인트**: 석탄·철과 원유는 **원동력·자원**, 렌즈는 **관찰 도구**, 플랫폼은 **기반 인프라**로서의 역할을 강조한다.

## 빅데이터 출현 배경

### ICT 발전에 따른 데이터 환경 변화

| 측면 | 변화 |
|---|---|
| 데이터 규모 | EB → ZB → YB (기하급수적 증가) |
| 데이터 유형 | 정형(DB) → 비정형(이메일, 영상, SNS) → 센서/사물정보(IoT, RFID) |
| 데이터 특성 | 구조화 → 다양성·복합성 → 실시간성 |

### 빅데이터 출현의 4가지 핵심 요인

| 요인 | 설명 |
|---|---|
| **데이터 규모 도달** | 가치 창출이 가능할 만큼 충분한 규모 달성 |
| **저장 기술 발전** | 저장 비용이 무어의 법칙보다 빠르게 감소 |
| **분석 기술 발전** | 빅데이터 처리 아키텍처·통계 도구 고도화 |
| **분산 컴퓨팅 기술** | MapReduce, 클라우드 기반 병렬처리로 비용 절감 |

> **핵심**: "데이터 규모·저장·분석·분산 처리 기술이 동시에 성숙"하면서 빅데이터 시대 도래

### 핵심 기술 개념

**MapReduce**
- HDFS에 분산 저장된 데이터를 데이터가 있는 노드에서 병렬 처리하는 빅데이터 처리 방식
- Map(개별 처리) → Shuffle(키별 그룹화) → Reduce(집계)

**클라우드 컴퓨팅**
- 인터넷을 통해 서버, 저장공간, 소프트웨어 등 IT 자원을 필요한 만큼 빌려 쓰는 방식
- 초기 인프라 투자 비용 절감, 탄력적 확장성, 온디맨드 리소스 활용 가능

### 출현 배경 — 교재 기준 3가지 ⭐

| 주체 | 내용 |
|---|---|
| 산업계 | 고객 데이터 축적이 임계점을 넘으며 **양질전환 법칙** — 양이 쌓이면 질적 변화가 일어남 |
| 학계 | 인간 게놈, 기상, 천문·물리 등 **거대 데이터를 다루는 학문 분야** 확산 |
| 관련 기술 발전 | 디지털화, 저장 기술 발전과 가격 하락, 인터넷 보급, 모바일 확산, **클라우드 컴퓨팅** 보편화 |

> 클라우드 컴퓨팅은 빅데이터 처리 비용을 획기적으로 낮춰 빅데이터 확산의 결정적 계기가 됨

### 빅데이터 처리 기술

| 기술 | 설명 |
|---|---|
| 하둡 | 대용량 데이터를 여러 서버에 **분산 저장(HDFS)하고 병렬 처리(맵리듀스)**하는 오픈소스 프레임워크 |
| 스파크 | 메모리 기반 분산 처리로 하둡 맵리듀스보다 빠름 |
| NoSQL | 스키마가 유연한 비관계형 DB — 1장 데이터베이스 참고 |

## 빅데이터로 인한 패러다임 변화

빅데이터 시대의 4가지 근본적 변화

| 변화 영역 | 기존 (Before) | 빅데이터 시대 (After) |
|---|---|---|
| **조사 방식** | 표본조사 | 전수조사 (비용 절감으로 전체 데이터 분석 가능) |
| **처리 시점** | 사전처리 (필요한 데이터만 선별) | 사후처리 (최대한 많이 수집 후 분석) |
| **중시 기준** | 질(Quality) | 양(Quantity) (많은 데이터가 오류 보정) |
| **분석 관점** | 인과관계 (왜?) | 상관관계 (패턴 인식) |

## 빅데이터 시대의 3가지 변화

### (1) 기술 변화
- **데이터 아키텍처 진화**: 중앙집중식 DB → Hadoop, Spark 등 분산·병렬 처리 시스템
- **클라우드 컴퓨팅**: 인프라 비용 절감, 탄력적 확장, 진입장벽 하락

### (2) 인재·조직 변화
- **데이터 사이언티스트 수요 급증**: 프로그래밍+통계+도메인 지식 필요
- **데이터 중심 조직**: CDO 신설, 전사 데이터 기반 의사결정 문화

### (3) 데이터 변화
- **규모 급증**: EB → ZB → YB 단위 증가
- **유형 다양화**: 정형 → 비정형 → 센서/IoT 데이터
- **처리 기술 고도화**: 실시간 스트리밍, ETL 자동화, 데이터 파이프라인
