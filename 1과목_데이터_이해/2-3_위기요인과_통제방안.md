# 위기 요인과 통제 방안

> 1과목 데이터 이해 › 2장 데이터의 가치와 미래

---

## 빅데이터의 위기 요인과 통제 방안

### 위기 요인 (3대 역기능)

| 위기 요인 | 설명 | 예시 |
|---|---|---|
| **사생활 침해** | 개인의 은밀한 행적 및 패턴 예측·노출 | 전력 사용량 분석으로 생활 패턴 추적 |
| **책임 원칙 훼손** | 미래 예측만으로 현재 개인에게 불이익 부과 | 범죄 위험도 알고리즘으로 무고한 자 감시 |
| **데이터 오용** | 편향·오염된 데이터로 잘못된 결정 | 과거 성별 편향 데이터로 학습한 채용 AI |

### 통제 방안 (해결 전략)

| 전략 | 설명 |
|---|---|
| **사용자 책임 강화** | 기업이 데이터로 입힌 실제 피해에 대한 법적 책임 엄격히 추궁 |
| **결과 기반 처벌** | 알고리즘 예측이 아닌 실제 행동 결과를 바탕으로 처벌 |
| **알고리즘 투명성 (XAI)** | 블랙박스 알고리즘에 대한 접근·심사 허용 및 설명 의무화 |

### 통제 방안 — 교재 표현 ⭐

| 위기 요인 | 통제 방안 | 핵심 |
|---|---|---|
| 사생활 침해 | **동의제에서 책임제로** | 개인정보 제공자의 동의에 기대지 말고, 사용 주체가 책임지도록 |
| 책임 원칙 훼손 | **결과 기반 책임 원칙 고수** | 예측만으로 처벌하지 않고 실제 행동 결과로 판단 |
| 데이터 오용 | **알고리즘 접근 허용** | 알고리즘을 해석하고 부당한 피해자를 구제하는 전문 인력 **알고리즈미스트** |

> 데이터 오용 예: 잘못된 지표를 맹신하는 경우 — 베트남 전쟁 당시 적군 사망자 수를 승리 지표로 삼은 사례

## 개인정보 비식별 조치 기술

빅데이터 안전 활용을 위한 5가지 기술

| 기술 | 방식 | 예시 |
|---|---|---|
| **데이터 마스킹** | 민감한 부분을 기호로 가리기 | 010-1234-5678 → 010-****-5678 |
| **가명처리** | 식별 정보를 다른 이름/코드로 대체 | 홍길동 → 사용자A, 001번 고객 |
| **총계 처리** | 개별 값 대신 합계/평균으로 표시 | 개인 연봉 → 개발팀 평균 연봉 |
| **데이터 값 삭제** | 식별 정보 항목 자체를 제거 | 서울시 서초구 서초동 1349-1 → 서울시 서초구 |
| **데이터 범주화** | 연속형 값을 구간으로 묶기 | 24세 → 20대 / 3,700만 원 → 3,000~4,000만 원 |

### 비식별 기법 세부 ⭐

| 기법 | 세부 기술 |
|---|---|
| 가명처리 | 휴리스틱 가명화, 암호화, 교환 방법 |
| 총계처리 | 총계처리, 부분 총계, 라운딩, 재배열 |
| 데이터 값 삭제 | 식별자 삭제, 식별자 부분 삭제, 레코드 삭제, 식별 요소 전부 삭제 |
| 데이터 범주화 | 감추기, 랜덤 라운딩, 범위 방법, 제어 라운딩 |
| 데이터 마스킹 | 임의 잡음 추가, 공백과 대체 |

### 비식별 적정성 평가 모델

| 모델 | 내용 |
|---|---|
| k-익명성 | 같은 값을 가진 레코드가 **k개 이상** 존재하도록 해 특정인 추론을 막음 |
| l-다양성 | 같은 그룹 안의 민감 정보가 **l개 이상의 다양한 값**을 갖도록 함 |
| t-근접성 | 그룹 내 민감 정보 분포가 **전체 분포와 t 이하로 차이** 나도록 함 |

## 개인정보 · 가명정보 · 익명정보

| 구분 | 내용 | 활용 |
|---|---|---|
| 개인정보 | 특정 개인을 알아볼 수 있는 정보 | 사전 동의 필요 |
| 가명정보 | **추가 정보 없이는** 특정 개인을 알아볼 수 없게 처리한 정보 | 통계 작성, 과학적 연구, 공익적 기록 보존 목적이면 동의 없이 가능 |
| 익명정보 | 더 이상 개인을 알아볼 수 **없게** 처리한 정보 | 제한 없이 활용 |
