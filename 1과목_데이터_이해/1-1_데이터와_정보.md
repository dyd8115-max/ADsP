# 데이터의 정의

- **데이터**: 가공되지 않은 순수한 사실이나 값 그 자체
- **정보**: 데이터를 가공/해석해서 의미를 부여한 것

---

## 데이터의 특성

| 구분 | 형태 | 예 |
|---|---|---|
| 존재적 특성 | 있는 그대로의 객관적 사실 | 수학 80점, 영어 90점 |
| 당위적 특성 | 추론·예측·전망·추정을 위한 근거 | 평균 90점 |

> 존재적 특성은 "사실 그 자체", 당위적 특성은 그 사실을 바탕으로 "판단/예측에 활용되는 근거"라는 차이

---

## 데이터 유형

### 1. 정성적 데이터 vs 정량적 데이터 (측정 기준에 따른 분류)

| 구분 | 정의 | 예시 |
|---|---|---|
| 정성적 데이터 | 기준이 명확하지 않아 수치로 표현하기 어려운 데이터 | 맛 평가("맛있다"), 소감, 인터뷰 답변, 색상 느낌 |
| 정량적 데이터 | 명확한 기준으로 수치화·집합으로 표현 가능한 데이터 | 키(170cm), 시험 점수(90점), 나이(25세) |

> 정성적 = 주관적/언어로 표현, 정량적 = 객관적/숫자로 표현

---

### 2. 정형 / 반정형 / 비정형 데이터 (구조에 따른 분류)

| 구분 | 정의 | 예시 |
|---|---|---|
| 정형 데이터 | - 미리 정해진 구조(스키마)에 맞춰 행과 열로 저장되는 데이터<br>- 연산 가능함 | RDB 테이블(엑셀, MySQL), CSV 파일 |
| 반정형 데이터 | - 구조가 있긴 하지만 고정된 스키마는 아닌, 일정한 형식을 가진 데이터<br>- 테이블보다 파일 형태로 저장, 가공을 거쳐 정형데이터로 변환 가능 | JSON, XML, HTML |
| 비정형 데이터 | - 정해진 구조가 없는 데이터<br>- 연산 불가, 관계 DB가 아닌 NoSQL DB에 저장 | 이미지, 동영상, 음성 파일, 텍스트 문서 |

> 정형은 "표 형태로 정리됨", 반정형은 "태그/키값 구조는 있지만 자유로움", 비정형은 "구조 자체가 없음"

---

### 3. 암묵지 / 형식지 (지식 표현 방식에 따른 분류)

| 구분 | 정의 | 예시 |
|---|---|---|
| 암묵지 | - 개인의 경험에 내재된 지식<br>- 언어/문서로 표현하기 어려움 | 노하우, 직관, 숙련된 기술(자전거 타기) |
| 형식지 | - 문서화·형식화되어 표현된 지식<br>- 전달과 공유가 쉬움 | 매뉴얼, 보고서, 데이터베이스 |

> 암묵지 = "말로 설명하기 힘든 몸에 익은 지식", 형식지 = "문서로 정리되어 공유 가능한 지식"

**상호작용 (SECI 모델)**

| 변환 과정 | 방향 | 설명 |
|---|---|---|
| 공통화 (Socialization) | 암묵지 → 암묵지 | 경험 공유를 통해 노하우가 전이됨 |
| 표출화 (Externalization) | 암묵지 → 형식지 | 노하우가 문서/언어로 형식화됨 |
| 연결화 (Combination) | 형식지 → 형식지 | 형식지들이 결합되어 새로운 형식지 생성 |
| 내면화 (Internalization) | 형식지 → 암묵지 | 형식지를 학습·체화하여 개인의 노하우가 됨 |

> 이 4단계가 순환하며 지식이 확산되는 구조를 **지식 나선**이라고 함

# DIKW 피라미드

데이터가 어떻게 가치 있는 지식/지혜로 발전하는지를 보여주는 모델

| 단계 | 정의 | 예시 |
|---|---|---|
| Data (데이터) | 가공되지 않은 순수한 사실/값 | "수학 80점", "영어 90점" |
| Information (정보) | 데이터를 가공·연관시켜 의미를 부여한 것 | "평균 85점" |
| Knowledge (지식) | 정보를 체계화·통합해서 만든 유용한 일반화 | "수학보다 영어 점수가 높은 편이다" |
| Wisdom (지혜) | 지식에 통찰/경험이 더해져 만들어진 가치 판단·창의적 아이디어 | "영어 쪽 전공/진로가 더 적합할 수 있다" |

> 데이터 → 정보 → 지식 → 지혜로 갈수록 "단순 사실"에서 "판단·통찰"로 추상화 수준이 올라감

**피라미드 구조 (위로 갈수록 양은 적고 가치는 높음)**

```
        Wisdom (지혜)
       Knowledge (지식)
     Information (정보)
        Data (데이터)
```

- 아래(Data)일수록: 양은 많지만 가치는 낮음, 가공 안 된 사실
- 위(Wisdom)일수록: 양은 적지만 가치는 높음, 판단/통찰 포함

# 데이터 단위

### 1. 비트 / 바이트

| 구분 | 정의 |
|---|---|
| 비트 (Bit) | 데이터를 표현하는 **최소 단위**, 0 또는 1의 값을 가짐 |
| 바이트 (Byte) | 비트 8개를 묶은 단위 (8bit = 1Byte), **문자를 표현하는 최소 단위** |

> 비트는 컴퓨터가 처리하는 최소 단위, 바이트는 의미 있는 문자 하나를 표현하는 단위

### 2. 데이터 단위 (크기 순서)

| 단위 | 표기 | 크기 |
|---|---|---|
| 비트 | Bit | 0 또는 1 |
| 바이트 | Byte | 8 Bit |
| 킬로바이트 | KB | 1,024 Byte |
| 메가바이트 | MB | 1,024 KB |
| 기가바이트 | GB | 1,024 MB |
| 테라바이트 | TB | 1,024 GB |
| 페타바이트 | PB | 1,024 TB |
| 엑사바이트 | EB | 1,024 PB |
| 제타바이트 | ZB | 1,024 EB |
| 요타바이트 | YB | 1,024 ZB |

> 단위가 한 단계 올라갈 때마다 1,024(2¹⁰)배씩 커짐

# 시험 포인트

## 데이터의 정의와 특성 — 교재 표현

| 구분 | 교재 표현 |
|---|---|
| 데이터 정의 | **추론과 추정의 근거를 이루는 사실** (옥스퍼드 대사전) |
| 존재적 특성 | 객관적 사실 그 자체 |
| 당위적 특성 | 추론·예측·전망·추정을 위한 근거 |
| 정성적 데이터 | 언어·문자 등으로 기술 — 비정형이라 저장·검색·분석에 **비용이 많이 듦** |
| 정량적 데이터 | 수치·도형·기호로 표현 — 정형화되어 **비용 소모가 적음** |

> SECI 모델은 노나카 이쿠지로가 제시한 지식 창조 메커니즘. 순서는 **공통화 → 표출화 → 연결화 → 내면화** ("공·표·연·내")

## DIKW 구분 문제 요령 ⭐

| 단계 | 판단 기준 | 예시 문장 |
|---|---|---|
| 데이터 | 가공 전 개별 사실 | A마트 볼펜 100원, B마트 200원 |
| 정보 | 데이터 간 관계·비교로 의미 도출 | A마트 볼펜이 더 싸다 |
| 지식 | 정보를 구조화해 **나의 행동**에 적용 | 더 싼 A마트에서 사야겠다 |
| 지혜 | 지식에 아이디어를 더한 **창의적 판단** | A마트의 다른 상품도 쌀 것이다 |
