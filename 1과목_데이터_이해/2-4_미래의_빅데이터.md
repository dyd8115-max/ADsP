# 미래의 빅데이터

> 1과목 데이터 이해 › 2장 데이터의 가치와 미래

---

## 빅데이터 활용 3요소의 변화 ⭐

| 요소 | 미래 모습 | 설명 |
|---|---|---|
| 데이터 | **모든 것의 데이터화** | 사물인터넷·웨어러블·센서로 일상의 모든 것이 데이터로 기록됨 |
| 기술 | **진화하는 알고리즘, 인공지능** | 딥러닝 등으로 스스로 학습하고 판단하는 알고리즘 |
| 인력 | **데이터 사이언티스트, 알고리즈미스트** | 데이터를 해석하는 전문가 + 알고리즘의 부당한 피해를 구제하는 전문가 |

> 활용 3요소(데이터·기술·인력)가 각각 어떻게 진화하는지를 묻는 형태로 출제된다.

---

## 데이터화

| 항목 | 내용 |
|---|---|
| 의미 | 현상을 정량화된 형태로 바꿔 표로 만들고 분석할 수 있게 하는 것 |
| 예 | 위치 → GPS 좌표, 인간관계 → 소셜 미디어 친구 관계, 감정 → 게시글·좋아요 |
| 사물인터넷 | 사물에 센서를 달아 스스로 데이터를 생성 — 데이터화를 가속 |
