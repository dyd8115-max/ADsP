# 빅데이터 분석과 전략 인사이트

> 1과목 데이터 이해 › 3장 가치 창조를 위한 데이터 사이언스와 전략 인사이트

---

## 빅데이터 열풍과 회의론

| 구분 | 내용 |
|---|---|
| 열풍 | 빅데이터를 새로운 성장 동력으로 보는 기대 확산 |
| 회의론의 원인 ① | 과거 CRM 등 대규모 IT 투자가 기대만큼 효과를 내지 못한 **부정적 학습 효과** |
| 회의론의 원인 ② | 빅데이터 성공 사례로 소개된 것 상당수가 **기존 분석 프로젝트를 포장**한 것 |

> 회의론을 넘으려면 데이터의 크기보다 **분석으로 무엇을 얻을 것인가**에 집중해야 한다.

---

## 빅데이터 분석에서 중요한 것 ⭐

| 잘못된 인식 | 올바른 방향 |
|---|---|
| 데이터가 크면 무조건 좋다 | 크기보다 **어떤 시각과 통찰을 얻느냐**가 중요 |
| 분석을 많이 하면 경쟁력이 생긴다 | **전략적 통찰이 없는 분석**은 경쟁 우위로 이어지지 않음 |
| 데이터가 모든 답을 준다 | 비즈니스 핵심에 대한 **질문**이 먼저 |

---

## 일차원적 분석 vs 전략 도출 가치 기반 분석 ⭐

| 구분 | 일차원적 분석 | 전략 도출 가치 기반 분석 |
|---|---|---|
| 범위 | 부서 단위, 업무 효율화 | 전사 차원, 사업 성과·경쟁 우위 |
| 관점 | 당면 문제 해결 | 환경 변화와 비즈니스 핵심 가치 고려 |
| 결과 | 비용 절감, 프로세스 개선 | 차별화 기회, 새로운 사업 기회 |

> 일차원적 분석으로 경험을 쌓고 → 사업 성과를 견인하는 요소를 파악해 → 전략 도출 가치 기반 분석으로 확장하는 것이 바람직하다.

### 산업별 일차원적 분석 애플리케이션 ⭐

| 산업 | 일차원적 분석 |
|---|---|
| 금융 서비스 | 신용점수 산정, 사기 탐지, 가격 책정, 프로그램 트레이딩, 클레임 분석, 고객 수익성 분석 |
| 소매업 | 판촉, 매대 관리, 수요 예측, 재고 보충, 가격 및 제조 최적화 |
| 제조업 | 맞춤형 상품 개발, 신상품 개발 |
| 운송업 | 일정 관리, 노선 배정, 수익 관리 |
| 헬스케어 | 약품 거래, 예비 진단, 질병 관리 |
| 병원 | 가격 책정, 고객 로열티, 수익 관리 |
| 에너지 | 트레이딩, 공급·수요 예측 |
| 커뮤니케이션 | 가격 계획 최적화, 고객 보유, 수요 예측, 생산 능력 계획, 네트워크 최적화, 고객 수익성 관리 |
| 서비스 | 콜센터 직원 관리, 서비스-수익 사슬 관리 |
| 정부 | 사기 탐지, 사례 관리, 범죄 방지, 수익 최적화 |
| 온라인 | 웹 지표 분석, 사이트 설계, 고객 추천 |
| 모든 사업 | 성과 관리 |

> "다음 중 ○○ 산업의 일차원적 분석이 아닌 것" 형태로 출제. 다른 산업의 항목을 섞어 오답을 만든다.
