# 데이터 사이언스

## 데이터 사이언스의 정의

**데이터 사이언스**: 정형 또는 비정형을 막론하고 다양한 데이터로부터 의미 있는 정보와 전략적 통찰을 추출해내는 학문

---

## 데이터 마이닝 vs 데이터 사이언스

두 개념은 비슷하지만 **본질적으로 다릅니다**

| 구분 | 데이터 마이닝 | 데이터 사이언스 |
|---|---|---|
| **초점** | 분석(Analysis)에만 포커스 | 분석 + 구현 + 전달 + 인사이트 도출 |
| **범위** | 데이터에서 패턴 발굴 | 비즈니스 문제 해결을 위한 통합 프로세스 |
| **목표** | 숨겨진 패턴 찾기 | 전략적 인사이트와 비즈니스 성과 창출 |
| **커뮤니케이션** | 상대적으로 덜 중요 | **매우 중요** (이해관계자와의 소통) |

> **핵심**: 데이터 사이언스는 "분석하고 → 효과적으로 구현하고 → 명확하게 전달하고 → 비즈니스 성과를 견인"하는 통합적 행위

---

## 데이터 사이언스의 특징

| 특징 | 설명 |
|---|---|
| **전략적 통찰 추구** | 단순 분석 결과가 아닌 비즈니스 인사이트 도출 |
| **비즈니스 핵심이슈 해결** | "왜 이런 현상이 일어나나?" "앞으로 어떻게 해야 하나?"에 답하기 |
| **사업 성과 견인** | 분석 결과가 실제 비즈니스 의사결정과 성과에 영향 미침 |
| **소통 중시** | 분석 결과를 이해하기 쉽게 설명하고 설득하는 능력 필수 |
| **핵심 요소 정확 겨냥** | 비즈니스 성과를 좌우하는 근본적 문제를 파악하고 집중 |

---

## 데이터 사이언스 구성 요소

데이터 사이언스는 3가지 핵심 요소의 교집합

```
        분석 (Statistics/ML)
            ↗ ↖
데이터 사이언스 → 교집합 영역
            ↖ ↗
IT 기술 + 비즈니스 분석
```

| 요소 | 역할 | 담당 영역 |
|---|---|---|
| **분석 (Analysis)** | 데이터로부터 패턴 및 인사이트 추출 | 통계학, 머신러닝, 알고리즘 |
| **IT 기술** | 대규모 데이터 처리 및 구현 | 데이터베이스, 프로그래밍, 아키텍처 |
| **비즈니스 분석** | 비즈니스 문제 정의 및 가치 창출 | 시장 이해, 비즈니스 로직, ROI 분석 |

> 3가지 요소 모두 필요하며, 어느 하나 부족하면 진정한 데이터 사이언스가 아님

## 데이터 사이언티스트의 역량

### 5-1. 하드스킬 (Hard Skills)

**빅데이터 이론적 지식**
- 관련 기법에 대한 깊이 있는 이해
- 빅데이터 처리 방법론 습득
- 통계 및 머신러닝 알고리즘 이해

**분석 기술의 숙련**
- 최적의 분석 설계 능력
- 노하우 축적을 통한 실무 숙련
- 도구 활용 능력 (Python, R, SQL 등)

### 5-2. 소프트스킬 (Soft Skills)

**통찰력 있는 분석**
- 창의적 사고로 새로운 각도 발굴
- 호기심으로 숨겨진 인사이트 찾기
- 논리적 비판으로 분석 결과 검증

**설득력 있는 전달**
- 스토리텔링으로 결과를 이야기처럼 표현
- 시각화로 복잡한 데이터를 명확하게 전달
- 이해관계자별 맞춤형 커뮤니케이션

**다분야 간 협력**
- 기술팀, 비즈니스팀, 경영진 간 소통
- 도메인 지식 습득 능력
- 팀 협력 능력

## 가트너(Gartner) 데이터 사이언스 모델

가트너가 제시한 데이터 사이언스의 4가지 핵심 역량

| 역량 | 설명 | 스킬 |
|---|---|---|
| **데이터 관리** | 대규모 데이터 수집, 저장, 정제, 관리 | DB 설계, ETL, 데이터 품질 관리 |
| **분석 모델링** | 통계 및 머신러닝 기법으로 인사이트 도출 | 통계학, 알고리즘, 모델 평가 |
| **비즈니스 분석** | 비즈니스 문제 정의 및 가치 창출 능력 | 비즈니스 이해, 요구사항 분석, ROI 평가 |
| **소프트스킬** | 통찰·전달·협력 능력 | 커뮤니케이션, 스토리텔링, 리더십 |

> 4가지 역량이 균형있게 갖춰져야 실무에서 성과를 낼 수 있음

## 데이터 사이언티스트 vs 데이터 엔지니어 vs 데이터 분석가

| 직무 | 주요 역할 | 핵심 스킬 |
|---|---|---|
| **데이터 사이언티스트** | 데이터로부터 인사이트 도출 → 비즈니스 문제 해결 | 통계, 머신러닝, 비즈니스 이해, 커뮤니케이션 |
| **데이터 엔지니어** | 대규모 데이터 처리·저장 인프라 구축·운영 | 프로그래밍, DB, 분산 처리, 아키텍처 |
| **데이터 분석가** | 기존 데이터 분석 및 리포팅 | SQL, 시각화, 비즈니스 분석, 엑셀 |

## 훌륭한 데이터 사이언스의 조건

| 조건 | 설명 |
|---|---|
| **정확한 문제 정의** | 비즈니스 핵심이슈가 무엇인지 파악<br>고객과 직원의 내면적 요구를 이해하고, 비즈니스 핵심가치가 무엇인지 통찰 |
| **인문학적 통찰력** | 소비자가 어디서 재미와 편의를 느끼는지 이해하기 위해 **과정**에 주목<br>단순 수치 분석을 넘어 인간의 심리·행동·가치관을 통찰 |
| **창의적 사고 능력** | 기존 사고의 틀을 벗어나 문제를 새로운 관점에서 바라보고 해결<br>데이터라는 도구를 창의적으로 활용해 혁신적 솔루션 도출 |
| **적절한 데이터 선택** | 필요한 데이터가 무엇인지 판단<br>인문학적 이해를 바탕으로 의미 있는 데이터를 선별 |
| **최적의 기법 적용** | 문제에 맞는 분석 방법 선택 |
| **명확한 소통** | 결과를 의사결정권자가 이해할 수 있게 전달<br>수치와 인사이트를 스토리텔링으로 표현 |
| **실제 행동 유도** | 분석 결과가 비즈니스 의사결정과 성과로 이어짐<br>고객 만족도와 조직의 지속적 가치 창출로 연결 |

## 데이터 사이언티스트에게 요구되는 능력

시대가 발전함에 따라 데이터 사이언티스트의 역할도 확장되고 있다.

### 과학과 인문학의 결합

**데이터 사이언티스트는 정량분석이라는 과학과 인문학적 통찰에 근거한 합리적 논의를 탁월하게 조합**해야 한다.

| 구분 | 내용 |
|---|---|
| **정량분석 (과학)** | 데이터 처리, 통계, 머신러닝 등 객관적 기법으로 패턴 발견 |
| **인문학적 통찰** | 왜 그런 패턴이 나타났는지, 고객이 무엇을 원하는지 깊이 있게 이해 |
| **합리적 논의** | 두 관점을 결합해 설득력 있는 주장과 솔루션 제시 |

### 인사이트의 수준

**데이터 사이언티스트는 단순히 정보를 활용하는 정도의 수준을 넘어, 사업 성과를 좌우하는 핵심적인 문제에 답할 수 있는 수준의 인사이트를 제시**해야 한다.

| 수준 | 설명 | 예시 |
|---|---|---|
| **정보 활용 수준** | 기초적인 데이터 분석만 제공 | "이번 분기 매출이 10% 증가했다" |
| **인사이트 제시 수준** | 현상의 원인과 의미를 분석 | "고객이 새로운 기능에 만족해서 구매가 증가했다" |
| **전략적 인사이트 수준** | 사업 방향을 바꾸는 핵심 통찰 제시 | "고객 만족도 높은 기능에 집중 투자하면, 경쟁 우위를 확보할 수 있다" |

## 데이터 사이언스 역량의 진화

| 시각 | 요구 능력 |
|---|---|
| **기술 중심** (과거) | 데이터 처리·통계·머신러닝 기술 |
| **통합적 접근** (현재) | 기술 + 비즈니스 이해 + 인문학적 통찰력 |
| **전략적 역할** (미래) | 기술 + 비즈니스 + 인문학 + **조직 의사결정 리더십** |

> **핵심**: 좋은 데이터 사이언스는 "숫자로만 이야기하지 않는다. 사람을 이해하고, 문제의 본질을 꿰뚫으며, 그 결과가 실제 비즈니스 성과와 인간의 삶의 질 향상으로 이어지게 한다. 또한 단순한 분석가를 넘어 조직의 미래를 결정하는 핵심 인사이트를 제시하는 전략가의 역할을 수행한다"

## 데이터 사이언스 vs 통계학 vs 데이터 마이닝

| 구분 | 대상 데이터 | 범위 |
|---|---|---|
| 통계학 | 주로 정형화된 실험 데이터 | 분석 |
| 데이터 마이닝 | 대용량 데이터 | 분석 (패턴 발견) |
| 데이터 사이언스 | **정형·비정형 모두** (숫자·문자·영상 등) | 분석 + 구현 + 전달 + 성과 |

### 구성 요소 — 교재 세부 항목

| 영역 | 세부 역량 |
|---|---|
| 분석 | 수학, 확률 모델, 머신러닝, 분석 방법론, 패턴 인식 |
| IT (데이터 관리) | 신호 처리, 프로그래밍, 데이터 엔지니어링, 데이터 웨어하우징, 고성능 컴퓨팅 |
| 비즈니스 분석 | 커뮤니케이션, 프레젠테이션, 스토리텔링, 시각화 |

## 인문학 열풍의 이유 ⭐

외부 환경 변화로 인문학적 사고가 중요해진 세 가지 이유

| 변화 | 내용 |
|---|---|
| 단순한 세계화 → **복잡한 세계화** | 규모의 경제·표준화(컨버전스)에서 다양성·각 사회의 독특함(디버전스)으로 |
| 제품 생산 → **서비스** | 고장 없는 제품보다 **고객에게 주는 경험**이 경쟁력 |
| 생산 → **시장 창조** | 기술 경쟁보다 현지 사회·문화를 이해해 **새 시장을 만드는 것**이 중요 |

---

## 정보 vs 통찰 ⭐

인문학적 사고는 단순한 **정보**를 넘어 **통찰**을 얻게 한다.

| 시점 | 정보 | 통찰 |
|---|---|---|
| 과거 | 무슨 일이 일어났는가? — **리포팅** | 어떻게, 왜 일어났는가? — **모델링, 실험 설계** |
| 현재 | 무슨 일이 일어나고 있는가? — **경고** | 차선 행동은 무엇인가? — **권고** |
| 미래 | 무슨 일이 일어날 것인가? — **추출** | 최악 또는 최선의 상황은? — **예측, 최적화, 시뮬레이션** |

> 같은 시점에서 왼쪽은 '무엇', 오른쪽은 '왜·어떻게·무엇을 해야'에 답한다.
