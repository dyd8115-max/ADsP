# 데이터 거버넌스 체계

## 데이터 거버넌스의 개념

| 항목 | 내용 |
|---|---|
| **정의** | 기업의 모든 데이터에 대해 **정책 및 지침, 표준화, 운영 조직 및 책임** 등의<br>표준화된 관리 체계를 수립하고, 운영을 위한 **프레임워크 및 저장소**를 구축하는 것 |
| **주요 관리 대상** | **마스터 데이터, 메타데이터, 데이터 사전** |

### 데이터 거버넌스 구성요소 ⭐

| 구성요소 | 내용 |
|---|---|
| **원칙 (Principle)** | 데이터를 유지·관리하기 위한 **지침과 가이드** |
| **조직 (Organization)** | 데이터를 관리할 조직의 **역할과 책임** |
| **프로세스 (Process)** | 데이터 관리를 위한 **활동과 체계** |

> **암기 요령**: **원칙 · 조직 · 프로세스** 3가지 (분석 거버넌스 5요소와 구분할 것)

---

## 데이터 거버넌스 체계

```mermaid
flowchart LR
    A["데이터 표준화"] --> B["데이터 관리 체계"] --> C["데이터 저장소 관리"] --> D["표준화 활동"]
    D -.->|지속적 개선| A
```

### 1️⃣ 데이터 표준화

| 항목 | 내용 |
|---|---|
| **구성 업무** | 데이터 표준 용어 설정, **명명 규칙 수립**,<br>**메타데이터 구축**, **데이터 사전 구축** |

> **데이터 표준 용어**: **표준 단어 사전, 표준 도메인 사전, 표준 코드** 등으로 구성되며,<br>사전 간 **상호 검증이 가능하도록 점검 프로세스를 포함**한다.

### 2️⃣ 데이터 관리 체계

| 항목 | 내용 |
|---|---|
| **원칙 수립** | **데이터 정합성 및 활용의 효율성**을 위하여<br>표준 데이터를 포함한 **메타데이터와 데이터 사전의 관리 원칙**을 수립 |
| **상세화** | 수립된 원칙에 근거하여 항목별 **상세 프로세스**를 만들고,<br>관리·운영을 위한 **담당자 및 조직별 역할과 책임**을 상세하게 준비 |
| **빅데이터 유의사항** | 데이터 양의 급증으로 **데이터 생명주기 관리 방안**을 수립하지 않으면<br>**데이터 가용성 및 관리 비용 증대** 문제에 직면 |

### 3️⃣ 데이터 저장소 관리

| 항목 | 내용 |
|---|---|
| **구성** | 메타데이터 및 표준 데이터를 관리하기 위한 **전사 차원의 저장소**를 구성 |
| **지원 기능** | 데이터 관리 체계 지원을 위한 **워크플로 및 관리용 응용 소프트웨어**를 지원하고,<br>관리 대상 시스템과의 **인터페이스를 통한 통제** 수행 |
| **영향 평가** | **데이터 구조 변경에 따른 사전 영향 평가**도 수행되어야 효율적인 활용이 가능 |

### 4️⃣ 표준화 활동

| 항목 | 내용 |
|---|---|
| **점검** | 데이터 거버넌스 체계를 구축한 후 **표준 준수 여부를 주기적으로 점검**하고 모니터링 실시 |
| **정착** | 거버넌스의 조직 내 안정적인 정착을 위한<br>**지속적인 변화 관리 및 주기적인 교육** 진행 |
| **개선** | **지속적인 데이터 표준화 개선활동**을 통해 실용성을 높여야 함 |

## 주요 관리 대상

| 대상 | 설명 |
|---|---|
| 마스터 데이터 | 업무 처리의 기준이 되는 핵심 데이터 — 고객·상품·조직 정보 등 |
| 메타데이터 | 데이터에 관한 데이터 — 구조·정의·출처 등 |
| 데이터 사전 | 데이터 요소의 이름·형식·의미를 정의한 목록 |

---

## 빅데이터 거버넌스의 특징 ⭐

빅데이터 거버넌스 = 데이터 거버넌스 체계 + 빅데이터의 **효율적 관리, 다양한 데이터 관리 체계, 데이터 최적화, 정보 보호, 데이터 생명주기 관리, 데이터 카테고리별 관리 책임자 지정**

| 특징 | 내용 |
|---|---|
| 데이터 품질 관리 | 모든 데이터의 품질을 관리하면 비용이 커지므로 **적정 수준의 품질 관리**와 **ERD 등 변경 관리**가 중요 |
| 데이터 최적화 | 데이터 양이 급증하므로 **보존 정책과 생명주기 관리**가 없으면 가용성 저하·비용 증대 |
| 정보 보호 | 개인정보 보호·보안 정책 |
| 관리 책임자 | 데이터 카테고리마다 **관리 책임자** 지정 |
| 적용 단위 | 산업 분야별, 데이터 유형별, 정보 거버넌스 요소별로 구분해 작성 |

> 빅데이터 분석에서 **품질 관리도 중요하지만, 데이터 생명주기 관리가 없으면 비용 증대**에 직면한다 — 교재 핵심 문장
