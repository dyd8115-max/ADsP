# 의사결정나무 ⭐⭐

| 항목 | 내용 |
|---|---|
| 정의 | 분류 규칙을 **나무 구조**로 나타내, 데이터를 반복적으로 나누며 분류·예측 |
| 분류나무 | 목표변수가 **범주형** |
| 회귀나무 | 목표변수가 **연속형** — 끝마디의 평균으로 예측 |

## 구성 요소

| 요소 | 설명 |
|---|---|
| 뿌리마디 | 맨 위 시작 마디 (전체 데이터) |
| 중간마디 | 부모와 자식이 모두 있는 마디 |
| 끝마디 | 자식이 없는 마디 — 최종 분류 결과 |
| 부모마디 / 자식마디 | 분리 전 / 분리 후 마디 |
| 가지 | 마디를 연결하는 선 |
| 깊이 | 뿌리부터 끝마디까지 중간마디의 수 |

## 분석 과정

**성장 → 가지치기 → 타당성 평가 → 해석 및 예측**

| 단계 | 내용 |
|---|---|
| 성장 | 분리 기준과 정지 규칙에 따라 나무를 키움 |
| 가지치기 | 과적합을 막기 위해 **불필요한 가지를 제거** — 오분류율을 크게 높이거나 부적절한 규칙을 가진 가지 |
| 타당성 평가 | 이익도표, 위험도표, 검증용 데이터로 평가 |
| 해석 및 예측 | 규칙 해석, 새 데이터 예측 |

> **정지 규칙**: 더 나눠도 불순도가 거의 줄지 않거나, 마디의 데이터 수가 너무 적거나, 깊이가 정해진 값에 도달하면 성장을 멈춘다.

## 분리 기준 ⭐

순수도가 **높아지도록**(불순도가 **낮아지도록**) 분리한다.

| 목표변수 | 분리 기준 | 방향 |
|---|---|---|
| **이산형** (분류나무) | **카이제곱 통계량**의 p-value | 작을수록 좋은 분리 |
| | **지니 지수** | 작을수록 순수 → 감소량이 큰 분리 선택 |
| | **엔트로피 지수** | 작을수록 순수 → 정보 이득이 큰 분리 선택 |
| **연속형** (회귀나무) | **분산분석 F 통계량**의 p-value | 작을수록 좋은 분리 |
| | **분산 감소량** | 클수록 좋은 분리 |

## 불순도 계산 ⭐

```
지니 지수 = 1 − Σ pᵢ²
엔트로피  = − Σ pᵢ · log₂ pᵢ
```

```
예) 한 마디에 A 6개, B 2개 (총 8개)
p(A) = 0.75, p(B) = 0.25
지니     = 1 − (0.75² + 0.25²) = 1 − (0.5625 + 0.0625) = 0.375
엔트로피 = −(0.75 × log₂0.75 + 0.25 × log₂0.25) ≈ 0.811

A 4개, B 4개 → 지니 0.5 (두 범주일 때 최대), 엔트로피 1 (최대)
A 8개, B 0개 → 지니 0, 엔트로피 0 (완전 순수)
```

## 대표 알고리즘 ⭐

| 알고리즘 | 분리 기준 | 분리 형태 |
|---|---|---|
| **CART** | 범주형: **지니 지수** / 연속형: **분산 감소량** | **이진 분리** |
| **C4.5, C5.0** | **엔트로피 지수** (정보 이득 비율) | 다지 분리 가능 |
| **CHAID** | 범주형: **카이제곱 통계량** / 연속형: **F 통계량** | 다지 분리, 가지치기 없이 적당한 크기에서 성장 중지 |

## 장단점

| 장점 | 단점 |
|---|---|
| 규칙이 직관적이라 **해석이 쉬움** | 분류 경계선 근처에서 오차가 큼 |
| **비모수적** — 선형성·정규성 등 가정 불필요 | **과적합** 가능성 |
| 이상값에 덜 민감 | 데이터가 조금만 바뀌어도 구조가 크게 변하는 **불안정성** |
| 범주형·연속형 모두 처리, 변수 선택 자동 | 각 변수의 영향력을 계수처럼 정량화하기 어려움 |

```r
library(rpart)
tree <- rpart(Species ~ ., data = iris, method = "class")
plot(tree); text(tree)
predict(tree, newdata = test, type = "class")

library(party)
ctree(Species ~ ., data = iris)      # 조건부 추론 나무 — 통계적 검정으로 분리
```

# 앙상블 ⭐⭐

여러 개의 모형을 만들어 결과를 **결합**해, 하나의 모형보다 안정적이고 정확한 예측을 얻는 방법

| 기법 | 방식 | 효과 |
|---|---|---|
| **배깅** | **붓스트랩 표본**을 여러 개 뽑아 각각 모형을 만들고 **다수결·평균** | **분산 감소** — 불안정한 모형(나무)에 효과적 |
| **부스팅** | 이전 모형이 **틀린 데이터에 가중치**를 더 주며 모형을 **순차적으로** 만듦 | **편향 감소**, 예측력 높음 / 과적합 주의 |
| **랜덤 포레스트** | 배깅 + 각 마디에서 **설명변수 일부를 무작위로 선택**해 분리 | 나무 간 상관을 줄여 성능 향상 |
| 스태킹 | 서로 다른 모형의 예측값을 입력으로 **최종 모형**을 학습 | |

| 비교 | 배깅 | 부스팅 |
|---|---|---|
| 학습 | **병렬** (독립적) | **순차적** (이전 결과 반영) |
| 표본 | 붓스트랩 복원추출 | 가중치 조정 |
| 대표 | 랜덤 포레스트 | 에이다부스트, GBM, XGBoost |

> 배깅에는 보통 **가지치기를 하지 않은 최대 나무**를 쓴다. 개별 나무의 분산이 커도 평균으로 상쇄되기 때문이다.

```r
library(randomForest)
rf <- randomForest(Species ~ ., data = iris, ntree = 500, importance = TRUE)
importance(rf)        # 변수 중요도 (지니 감소량 등)
varImpPlot(rf)
```

# 인공신경망 ⭐

| 항목 | 내용 |
|---|---|
| 구조 | **입력층 → 은닉층 → 출력층** |
| 뉴런 | 입력값 × 가중치의 합 + 편향 → **활성화 함수**를 거쳐 출력 |
| 학습 | **역전파 알고리즘** — 출력 오차를 **출력층에서 입력층 방향으로** 전달하며 가중치를 조정 (경사하강법) |

## 활성화 함수

| 함수 | 출력 | 쓰임 |
|---|---|---|
| 계단 함수 | 0 또는 1 | 초기 퍼셉트론 |
| 부호 함수 | −1 또는 1 | |
| **시그모이드** | 0 ~ 1 | 이진 분류 출력, 로지스틱 회귀와 같은 형태 |
| **소프트맥스** | 각 범주의 확률 (합 = 1) | **다범주 분류의 출력층** |
| tanh | −1 ~ 1 | |
| **ReLU** | 0 또는 입력값 그대로 | 은닉층 — **기울기 소실 완화** |

## 핵심 개념

| 개념 | 설명 |
|---|---|
| 단층 퍼셉트론의 한계 | **XOR 문제**처럼 선형 분리가 안 되는 문제를 못 풂 → 은닉층을 둔 다층 퍼셉트론으로 해결 |
| 기울기 소실 | 층이 깊을수록 역전파 시 기울기가 0에 가까워져 앞쪽 층이 학습되지 않음 — 시그모이드에서 심함 |
| 은닉층·노드 수 | 너무 많으면 **과적합**, 너무 적으면 **과소적합** — 분석자가 정하는 값 |
| 초기 가중치 | 초기값에 따라 결과가 달라지고 **지역 최적해**에 빠질 수 있음 |
| 입력변수 | 범주형은 더미 변환, 연속형은 **표준화** 필요 |

| 장점 | 단점 |
|---|---|
| 복잡한 **비선형** 관계 학습 | 결과 **해석이 어려움** (블랙박스) |
| 잡음에 비교적 강함 | 학습 시간이 길고, 은닉층·노드 수 결정이 어려움 |

```r
library(nnet)
nn <- nnet(Species ~ ., data = iris, size = 2)                  # size = 은닉 노드 수

library(neuralnet)
nn2 <- neuralnet(y ~ x1 + x2, data = df, hidden = c(3, 2))      # 은닉층 2개
```

# 그 밖의 분류 기법

| 기법 | 핵심 | 특징 |
|---|---|---|
| **나이브 베이즈** | 베이즈 정리 + 설명변수들이 서로 **조건부 독립**이라고 가정 | 빠르고 단순, 텍스트·스팸 분류에 강함 |
| **k-최근접 이웃** | 새 데이터와 **가장 가까운 k개** 이웃의 다수결 | 학습 단계 없음(게으른 학습), **k가 작으면 과적합 · 크면 과소적합**, 거리 계산 전 **표준화** 필요 |
| **서포트 벡터 머신** | 두 범주 사이 **마진을 최대로** 하는 경계 — 경계에 가장 가까운 점들이 **서포트 벡터** | 커널 함수로 **비선형** 분류 가능, 해석 어려움 |

# 시험 포인트

| 주제 | 핵심 |
|---|---|
| 의사결정나무 과정 | 성장 → 가지치기 → 타당성 평가 → 해석 및 예측 |
| 이산형 분리 기준 | 카이제곱 p-value, 지니, 엔트로피 |
| 연속형 분리 기준 | F 통계량 p-value, 분산 감소량 |
| CART | 지니·분산 감소, **이진 분리** |
| C4.5 / C5.0 | 엔트로피 |
| CHAID | 카이제곱·F 통계량, 다지 분리 |
| 배깅 | 붓스트랩 + 다수결, 분산 감소 |
| 부스팅 | 오분류에 가중치, 순차 학습, 편향 감소 |
| 랜덤 포레스트 | 배깅 + 변수 무작위 선택 |
| 역전파 | 출력층 → 입력층 방향으로 오차 전달 |
| 소프트맥스 | 다범주 출력층 |
| 나이브 베이즈 | 조건부 독립 가정 |
