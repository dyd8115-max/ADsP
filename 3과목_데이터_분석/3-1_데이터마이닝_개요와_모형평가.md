# 데이터 마이닝 개요와 모형 평가

> 3과목 데이터 분석 › 3장 정형 데이터 마이닝

---

## 데이터 마이닝이란

| 항목 | 내용 |
|---|---|
| 정의 | 대용량 데이터에서 **의미 있는 패턴과 규칙을 발견**해 의사결정에 활용하는 과정 |
| 통계분석과 차이 | 통계분석은 **가설·가정**을 세우고 검증, 데이터 마이닝은 다양한 알고리즘으로 **가설 없이 패턴 탐색** |

### 데이터 마이닝 기법 분류 ⭐

| 구분 | 지도학습 | 비지도학습 |
|---|---|---|
| 정답(목표변수) | 있음 | 없음 |
| 목적 | 분류·예측 | 구조·패턴 발견 |
| 기법 | 로지스틱 회귀, 의사결정나무, 인공신경망, 앙상블, 서포트 벡터 머신, k-최근접 이웃, 나이브 베이즈, 회귀분석 | 군집분석, 연관분석, 주성분분석, 자기조직화지도, 다차원척도법 |

| 과업 | 설명 | 예 |
|---|---|---|
| 분류 | 범주를 예측 | 이탈 여부, 스팸 여부 |
| 예측·추정 | 연속형 값을 예측 | 매출액, 집값 |
| 군집 | 비슷한 개체끼리 묶음 | 고객 세분화 |
| 연관 | 함께 일어나는 항목 | 장바구니 분석 |
| 기술 | 데이터의 특징을 설명 | 고객 프로파일 |

### 데이터 마이닝 추진 단계

목적 설정 → 데이터 준비 → 데이터 가공 → 기법 적용 → 검증

## 데이터 분할 ⭐

| 데이터 | 비율 (교재) | 용도 |
|---|---|---|
| 훈련용 | **50%** | 모형 학습 |
| 검증용 | **30%** | 과적합 확인, 하이퍼파라미터 조정, 모형 선택 |
| 테스트용 | **20%** | **최종 성능 평가** — 학습에는 전혀 쓰지 않음 |

> 데이터가 충분하지 않으면 훈련·테스트 두 개로만 나누거나 **교차검증**을 쓴다.

### 과적합과 과소적합

| 구분 | 의미 | 증상 |
|---|---|---|
| 과적합 | 훈련 데이터의 잡음까지 학습 | 훈련 성능 높음, **테스트 성능 낮음** |
| 과소적합 | 모형이 너무 단순 | 훈련·테스트 모두 성능 낮음 |

### 교차검증 ⭐

| 방법 | 설명 |
|---|---|
| 홀드아웃 | 데이터를 한 번만 훈련·테스트로 나눔 — 간단하지만 나누는 방식에 결과가 좌우됨 |
| **k-겹 교차검증** | 데이터를 k개로 나눠 **k−1개로 학습, 1개로 검증**을 **k번** 반복하고 평균 |
| LOOCV | 하나만 검증용으로 빼고 나머지로 학습 — k = n인 k-겹 교차검증 |
| **붓스트랩** | **복원추출**로 훈련 데이터를 만들고, 한 번도 뽑히지 않은 데이터(**약 36.8%**)로 검증 |

> 붓스트랩에서 어떤 데이터가 한 번도 안 뽑힐 확률 = (1 − 1/n)ⁿ ≈ **0.368** → 훈련에는 **약 63.2%**가 쓰인다.

### 클래스 불균형

| 방법 | 설명 |
|---|---|
| 언더샘플링 | 다수 범주를 줄임 — 정보 손실 |
| 오버샘플링 | 소수 범주를 늘림 — 과적합 위험, **SMOTE**는 가상 데이터를 생성 |
| 가중치 조정 | 소수 범주 오분류에 더 큰 비용 |

> 불균형 데이터에서는 **정확도만 보면 안 된다**. 99%가 정상인 데이터에서 전부 정상이라고 예측해도 정확도는 99%.

## 분류 모형 평가 — 혼동행렬 ⭐⭐

| | **예측: 양성** | **예측: 음성** |
|---|---|---|
| **실제: 양성** | TP (참 양성) | FN (거짓 음성) |
| **실제: 음성** | FP (거짓 양성) | TN (참 음성) |

| 지표 | 공식 | 의미 |
|---|---|---|
| **정확도** | (TP + TN) / 전체 | 전체 중 맞힌 비율 |
| **오분류율** | (FP + FN) / 전체 | 1 − 정확도 |
| **민감도** = 재현율 | **TP / (TP + FN)** | **실제 양성** 중 양성으로 맞힌 비율 |
| **특이도** | **TN / (TN + FP)** | **실제 음성** 중 음성으로 맞힌 비율 |
| **정밀도** | **TP / (TP + FP)** | **양성으로 예측한 것** 중 실제 양성 비율 |
| 거짓 양성률 | FP / (TN + FP) | **1 − 특이도** |
| **F1 점수** | 2 × 정밀도 × 재현율 / (정밀도 + 재현율) | 정밀도와 재현율의 조화평균 |

> **헷갈림 방지**: 분모를 보자. 민감도·특이도는 **실제** 기준, 정밀도는 **예측** 기준.

### 계산 예 ⭐

```
            예측 양성   예측 음성
실제 양성      40          10        ← 실제 양성 50
실제 음성      20          30        ← 실제 음성 50

정확도 = (40 + 30) / 100 = 0.70
민감도 = 40 / (40 + 10)  = 0.80
특이도 = 30 / (30 + 20)  = 0.60
정밀도 = 40 / (40 + 20)  ≈ 0.667
F1     = 2 × 0.667 × 0.8 / (0.667 + 0.8) ≈ 0.727
```

> R `caret::confusionMatrix()` 출력에서는 민감도가 `Sensitivity`, 특이도가 `Specificity`, 정밀도가 `Pos Pred Value`로 표시된다.

> **주의**: 혼동행렬에서 실제가 행인지 열인지는 문제마다 다르다. 표의 제목부터 확인할 것.

## ROC 곡선과 AUC ⭐

| 항목 | 내용 |
|---|---|
| ROC 곡선 | 분류 기준값을 바꿔가며 **x축: 거짓 양성률(1 − 특이도)**, **y축: 민감도**를 그린 곡선 |
| 좋은 모형 | 곡선이 **왼쪽 위 모서리**에 가까움 |
| AUC | ROC 곡선 아래 면적 — **1에 가까울수록** 좋음, **0.5면 무작위 분류** 수준 |

| AUC | 평가 |
|---|---|
| 0.9 ~ 1.0 | 매우 우수 |
| 0.8 ~ 0.9 | 우수 |
| 0.7 ~ 0.8 | 양호 |
| 0.6 ~ 0.7 | 미흡 |
| 0.5 ~ 0.6 | 실패 |

```r
library(ROCR)
pred <- prediction(예측확률, 실제값)
perf <- performance(pred, "tpr", "fpr")
plot(perf)
performance(pred, "auc")@y.values
```

## 이익도표와 향상도 곡선 ⭐

| 항목 | 내용 |
|---|---|
| 방법 | 예측 확률이 높은 순으로 정렬해 **10개 구간**으로 나누고, 구간별 실제 반응률을 확인 |
| 향상도 | **구간 반응률 / 전체 기본 반응률** |
| 좋은 모형 | 상위 구간의 향상도가 **크고**, 아래로 갈수록 **빠르게 감소** |

```
기본 반응률 10%, 상위 10% 구간 반응률 40%  →  향상도 = 40 / 10 = 4
```

> 향상도가 구간별로 들쭉날쭉하거나 평평하면 예측력이 낮은 모형이다.

|---|---|

## 시험 포인트

| 주제 | 핵심 |
|---|---|
| 분할 비율 | 훈련 50 / 검증 30 / 테스트 20 |
| 붓스트랩 | 복원추출, 안 뽑힐 확률 약 36.8% |
| k-겹 | k−1개 학습, 1개 검증, k번 반복 |
| 민감도 | TP/(TP+FN) = 재현율 |
| 특이도 | TN/(TN+FP) |
| 정밀도 | TP/(TP+FP) |
| ROC | x: 1−특이도, y: 민감도, AUC 0.5 = 무작위 |
| 향상도 | 구간 반응률 / 기본 반응률, 상위에서 크고 빠르게 감소 |
