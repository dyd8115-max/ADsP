# 데이터 마트

> 3과목 데이터 분석 › 1장 R기초와 데이터 마트

---

효율적인 데이터 분석을 위해 **분석 목적에 맞춰 데이터를 수집·변형하는 과정**이 필요하다.

---

## 데이터 마트의 개념

| 구분 | 정의 |
|---|---|
| **데이터 웨어하우스 (DW)** | 여러 시스템에 흩어진 데이터를 **분석 목적으로 통합·축적**해둔 장소 |
| **데이터 마트 (DM)** | DW로부터 특정 사용자가 관심을 갖는 데이터들을<br>**주제별·부서별로 추출하여 모은** 비교적 작은 규모의 데이터 웨어하우스 |
| **마트 개발** | 분석한 데이터를 **목적·주제·부서별로 나누어** 데이터 마트를 구현하는 행위 |

### 데이터 흐름

```
운영 DB  →  ETL  →  데이터 웨어하우스  →  데이터 마트  →  분석
(주문·회원·재고)      (전사 통합)         (영업·재무·마케팅)
```

### 비교

| 구분 | 운영 DB | 데이터 웨어하우스 | 데이터 마트 |
|---|---|---|---|
| **목적** | 거래 처리 | 전사 분석 | 부서·주제별 분석 |
| **처리 방식** | **OLTP** (쓰기 중심) | **OLAP** (읽기 중심) | OLAP |
| **범위** | 개별 업무 시스템 | 전사 통합 | DW의 **부분집합** |
| **데이터** | 현재 시점 | 과거~현재 누적 | 필요한 주제만 |
| **갱신** | 실시간 삽입·수정·삭제 | 주기적 적재, **비휘발성** | DW에서 추출 |

### DW의 4가지 특징 ⭐

| 특징 | 설명 |
|---|---|
| **주제 지향성** | 업무가 아닌 **주제(고객·상품·매출)** 중심으로 구성 |
| **통합성** | 여러 시스템의 데이터를 **일관된 형식으로 통합** |
| **시계열성** | 특정 시점 기준으로 **과거 이력을 축적** |
| **비휘발성** | 한 번 저장되면 **삭제·변경되지 않음** |

> **관계 요약**: **운영 DB → DW → 마트**로 데이터가 흐르며, **DW ⊃ 데이터 마트**의 포함 관계를 갖는다.

> **R에서 제공하는 패키지로 데이터 마트 구현 가능**: `reshape`, `sqldf`, `plyr`

# 데이터 전처리

데이터 마트에 필요한 데이터를 담았다면, **분석 단계에 들어가기 전에 전처리 과정**이 필요하다.

전처리에는 **데이터를 정제하는 과정**과 **분석 변수를 처리하는 과정**이 포함된다.

```mermaid
flowchart LR
    A["데이터 마트 구축"] --> B["데이터 정제"]
    B --> C["분석 변수 처리"]
    C --> D["분석 단계"]
```

## 1️⃣ 데이터 정제

크게 **결측값과 이상값을 처리**하는 내용으로 이루어진다.

| 대상 | 설명 |
|---|---|
| **결측값 (Missing Value)** | 값이 누락된 데이터 (`NA`) |
| **이상값 (Outlier)** | 정상 범위를 크게 벗어난 극단적인 값 |

## 2️⃣ 분석 변수 처리

| 과정 | 설명 |
|---|---|
| **변수 선택** | 분석에 필요한 변수만 골라냄 |
| **차원 축소** | 변수의 개수를 줄여 복잡도를 낮춤 |
| **파생변수 생성** | 기존 변수를 조합해 새로운 변수를 만듦 |
| **변수 변환** | 스케일 조정, 로그 변환 등 |
| **클래스 불균형** | 특정 범주에 데이터가 치우친 문제를 조정 |

---

## 요약변수와 파생변수 ⭐

| 구분 | 요약변수 | 파생변수 |
|---|---|---|
| 정의 | 수집된 정보를 분석에 맞게 **종합(집계)**한 변수 | 분석자가 **특정 조건이나 함수**로 값을 만들어 **의미를 부여**한 변수 |
| 특징 | 데이터 마트의 가장 기본 변수, 여러 모델에 공통으로 쓰여 **재활용성이 높음** | 분석자의 판단이 들어가 **주관적일 수 있으므로 논리적 타당성**을 갖춰야 함 |
| 예시 | 기간별 구매 금액·횟수, 상품별 구매 금액·횟수, 상품별 구매 순서, 유통 채널별 구매 금액, 단어 빈도, 초기 행동 변수, 트렌드 변수, 연속형 변수의 구간화 | 근무시간 구매 지수, 주 구매 매장, 주 활동 지역, 주 구매 상품, **구매 상품 다양성**, 선호 가격대, 시즌 선호 고객, 라이프 스테이지, 라이프스타일, 휴면 가능성, 최적 통화 시간 |

> **구분 요령**: 단순히 **합계·횟수로 모은 것**은 요약변수, 분석자가 **"이런 고객"이라고 의미를 붙인 것**은 파생변수

### 변수 처리 보충

| 기법 | 설명 |
|---|---|
| 구간화 | 연속형 변수를 몇 개의 구간으로 나눠 범주형으로 변환 — 이상값 영향 감소, 해석 용이 |
| 정규화 | 최소-최대 변환으로 0~1 범위로 맞춤 |
| 표준화 | 평균 0, 표준편차 1로 맞춤 — `scale()` |
| 로그 변환 | 오른쪽 꼬리가 긴 분포를 대칭에 가깝게 |
| 언더샘플링 | 다수 범주 데이터를 줄여 균형을 맞춤 — 정보 손실 위험 |
| 오버샘플링 | 소수 범주 데이터를 늘려 균형을 맞춤 — **SMOTE**는 소수 범주 이웃 사이에 가상 데이터를 생성 |

## 1️⃣ reshape 패키지

데이터 마트 개발에 자주 사용되는 **`melt`와 `cast`**를 비롯해 **20여 가지의 함수**를 보유한다.

### melt 함수

데이터를 **특정 변수를 기준으로 "녹여서"** 나머지 변수에 대한 **세분화된 데이터**를 만든다.

```r
library(reshape)

df <- data.frame(
  name = c("홍길동", "김철수"),
  국어 = c(90, 70),
  영어 = c(80, 85)
)
#     name 국어 영어
# 1 홍길동   90   80
# 2 김철수   70   85

melt(df, id = "name")     # name을 기준으로 녹임
#     name variable value
# 1 홍길동     국어    90
# 2 김철수     국어    70
# 3 홍길동     영어    80
# 4 김철수     영어    85
```

> **핵심**: **넓은(wide) 형태 → 긴(long) 형태**로 바꾼다. `id`로 지정한 변수는 기준으로 남고, 나머지는 `variable`과 `value` 두 열로 쪼개진다.

### cast 함수

**melt에 의해 녹은 데이터**를 요약을 위해 **새롭게 가공**하도록 돕는다.

```r
m <- melt(df, id = "name")

cast(m, name ~ variable)          # 원래 형태로 복원
#     name 국어 영어
# 1 김철수   70   85
# 2 홍길동   90   80

cast(m, name ~ ., mean)           # 사람별 평균
#     name (all)
# 1 김철수   77.5
# 2 홍길동   85.0

cast(m, variable ~ ., mean)       # 과목별 평균
```

> **표기 규칙**: `cast(데이터, 행 ~ 열, 요약함수)` 형태로 쓴다. `.`은 "나머지 전체"를 의미한다.

| 함수 | 방향 | 역할 |
|---|---|---|
| **`melt`** | wide → long | 데이터를 **녹임** (세분화) |
| **`cast`** | long → wide | 데이터를 **굳힘** (요약·재구성) |

### reshape2 패키지

reshape를 개선한 패키지로, `cast` 대신 **반환 형태별로 함수가 나뉜다**.

| 함수 | 반환 |
|---|---|
| `melt()` | 긴 형태 데이터프레임 |
| `dcast()` | **데이터프레임**으로 재구성 |
| `acast()` | **벡터·행렬·배열**로 재구성 |

```r
library(reshape2)
m <- melt(df, id.vars = "name")
dcast(m, name ~ variable)       # 원래 넓은 형태로
dcast(m, name ~ ., mean)        # 사람별 평균
```

## 2️⃣ sqldf 패키지

**표준 SQL 문장을 활용하여 R에서 데이터프레임을 다루는 것을 가능하게** 해주는 패키지다.

> SAS의 **PROC SQL**과 같은 역할을 한다.

```r
library(sqldf)

# 전체 조회
sqldf("select * from iris")

# 조건 조회
sqldf("select * from iris where Species = 'setosa'")

# 상위 5행
sqldf("select * from iris limit 5")

# 그룹별 집계
sqldf("select Species, avg(Sepal_Length) 
       from iris group by Species")

# 정렬
sqldf("select * from iris order by Sepal_Length desc")
```

### R 함수와의 대응

| SQL | R |
|---|---|
| `select * from df` | `df` |
| `select * from df limit 5` | `head(df, 5)` |
| `where 조건` | `subset(df, 조건)` |
| `group by` | `tapply()` , `aggregate()` |
| `order by` | `df[order(df$col), ]` |

> **주의**: 변수명에 `.`(마침표)이 있으면 SQL에서 인식하지 못하므로 **`_`(언더바)로 바꿔서** 사용해야 한다. (`Sepal.Length` → `Sepal_Length`)

## 3️⃣ plyr 패키지

**`apply` 함수를 기반**으로 데이터를 **분리하고 다시 결합**하는 가장 필수적인 데이터 처리 기능을 제공한다.

**입력되는 데이터 구조와 출력되는 데이터 구조에 따라** 여러 가지 함수를 지원한다.

### 함수 이름 규칙 ⭐

함수명이 **`입력 + 출력 + ply`** 구조로 되어 있다.

| 문자 | 의미 |
|---|---|
| **`d`** | data.frame (데이터프레임) |
| **`l`** | list (리스트) |
| **`a`** | array (배열) |

| 함수 | 입력 | 출력 |
|---|---|---|
| **`ddply`** | 데이터프레임 | 데이터프레임 |
| **`ldply`** | 리스트 | 데이터프레임 |
| **`dlply`** | 데이터프레임 | 리스트 |
| **`adply`** | 배열 | 데이터프레임 |
| **`llply`** | 리스트 | 리스트 |

> **읽는 법**: `ddply` = **d**ata.frame을 받아 **d**ata.frame으로 반환. 앞글자가 입력, 뒷글자가 출력이다.

### ddply — 가장 많이 쓰이는 함수

**데이터프레임을 그룹으로 나눠 연산한 뒤 다시 데이터프레임으로 합친다.**

```r
library(plyr)

# 기본 형태: ddply(데이터, 그룹기준, 함수, 계산식)

ddply(iris, "Species", summarise,
      평균 = mean(Sepal.Length))
#      Species    평균
# 1     setosa   5.006
# 2 versicolor   5.936
# 3  virginica   6.588

# 여러 통계량 동시에
ddply(iris, "Species", summarise,
      평균 = mean(Sepal.Length),
      표준편차 = sd(Sepal.Length),
      개수 = length(Sepal.Length))

# transform — 기존 열을 유지하며 새 열 추가
ddply(iris, "Species", transform,
      편차 = Sepal.Length - mean(Sepal.Length))
```

| 옵션 | 기능 |
|---|---|
| **`summarise`** | 요약 결과만 반환 (**그룹당 1행**) |
| **`transform`** | 기존 데이터에 **계산 결과 열을 추가** |

> **동작 원리 (Split-Apply-Combine)**: 데이터를 그룹으로 **분리(Split)** → 각 그룹에 함수 **적용(Apply)** → 결과를 **결합(Combine)**

```mermaid
flowchart LR
    A["전체 데이터"] --> B["그룹별 분리<br>Split"]
    B --> C["함수 적용<br>Apply"]
    C --> D["결과 결합<br>Combine"]
```

## 4️⃣ data.table 패키지

| 항목 | 내용 |
|---|---|
| **정의** | 데이터프레임과 유사하지만, **특정 칼럼별로 주솟값을 갖는 인덱스를 생성**하여<br>연산 및 검색을 빠르게 수행할 수 있는 데이터 구조 |
| **성능** | 기존 데이터프레임보다 **적게는 4배, 크게는 100배**에 가까운 빠른 속도로<br>데이터를 **탐색·연산·정렬·병합**할 수 있게 함 |

```r
library(data.table)

dt <- data.table(iris)          # 데이터프레임 → 데이터테이블
setkey(dt, Species)             # 인덱스(키) 생성

dt[Species == "setosa"]         # 인덱스를 활용한 빠른 검색

# 그룹별 집계
dt[, mean(Sepal.Length), by = Species]
```

> **빠른 이유**: 일반 데이터프레임은 조건 검색 시 **전체를 순회**하지만, data.table은 **인덱스(주솟값)로 바로 접근**하기 때문이다. DB의 인덱스와 같은 원리다.
