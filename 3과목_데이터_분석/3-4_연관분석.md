# 연관분석

> 3과목 데이터 분석 › 3장 정형 데이터 마이닝

---

## 연관분석이란

| 항목 | 내용 |
|---|---|
| 정의 | 거래 데이터에서 **함께 발생하는 항목**의 규칙을 찾는 분석 — **장바구니 분석** |
| 규칙 형태 | **"A를 사면 B도 산다"** (A → B, 조건 → 결과) |
| 학습 | 목표변수가 없는 **비지도 학습** |
| 활용 | 상품 진열, 묶음 판매, 교차 판매, 추천 |

---

## 평가 지표 ⭐⭐

| 지표 | 공식 | 의미 |
|---|---|---|
| **지지도** | P(A ∩ B) = A와 B를 **함께 포함한 거래 수 / 전체 거래 수** | 규칙이 얼마나 **자주** 나타나는가 |
| **신뢰도** | P(B \| A) = P(A ∩ B) / P(A) | A를 산 거래 중 B도 산 비율 — 규칙의 **정확도** |
| **향상도** | P(B \| A) / P(B) = P(A ∩ B) / (P(A) · P(B)) | A를 샀다는 정보가 B 구매 가능성을 **몇 배 높이는가** |

| 향상도 | 해석 |
|---|---|
| **> 1** | 양의 관계 — 함께 구매되는 **보완재** |
| **= 1** | 서로 **독립** — 우연히 같이 나온 것 |
| **< 1** | 음의 관계 — 함께 사지 않는 **대체재** |

> 지지도와 향상도는 A → B와 B → A가 **같고**, 신뢰도는 **다르다**.

## 계산 예 ⭐⭐

```
거래 1: 우유, 빵
거래 2: 우유, 기저귀, 맥주
거래 3: 빵, 기저귀, 맥주
거래 4: 우유, 빵, 기저귀, 맥주
거래 5: 우유, 빵, 기저귀
```

**규칙: 기저귀 → 맥주**

```
P(기저귀)        = 4/5 = 0.8     (거래 2, 3, 4, 5)
P(맥주)          = 3/5 = 0.6     (거래 2, 3, 4)
P(기저귀 ∩ 맥주) = 3/5 = 0.6     (거래 2, 3, 4)

지지도 = 0.6
신뢰도 = 0.6 / 0.8 = 0.75
향상도 = 0.75 / 0.6 = 1.25     → 1보다 큼, 함께 구매하는 경향
```

**규칙: 우유 → 빵**

```
P(우유) = 0.8, P(빵) = 0.8, P(우유 ∩ 빵) = 3/5 = 0.6   (거래 1, 4, 5)

지지도 = 0.6
신뢰도 = 0.6 / 0.8 = 0.75
향상도 = 0.75 / 0.8 = 0.9375   → 1보다 작음, 신뢰도가 높아도 의미 있는 규칙이 아님
```

> **포인트**: 신뢰도가 같아도 향상도는 다를 수 있다. 원래 잘 팔리는 상품(빵)은 신뢰도가 높게 나오기 쉬우므로 **향상도로 걸러야** 한다.

**표 형태 문제**

```
전체 거래 1,000건, A 포함 300건, B 포함 200건, A와 B 함께 100건

지지도         = 100 / 1000 = 0.1
신뢰도(A → B)  = 100 / 300  ≈ 0.333
신뢰도(B → A)  = 100 / 200  = 0.5
향상도         = 0.333 / 0.2 ≈ 1.67
```

## 아프리오리 알고리즘 ⭐

모든 항목 조합을 다 계산하면 조합 수가 폭발적으로 늘어나므로, **최소 지지도** 이상인 **빈발 항목집합**만 찾아 규칙을 만든다.

| 원리 | 내용 |
|---|---|
| 빈발 항목집합의 성질 | 어떤 항목집합이 빈발하면 **그 부분집합도 모두 빈발** |
| 가지치기 근거 | 어떤 항목집합이 빈발하지 않으면 **그것을 포함한 상위 집합도 빈발하지 않음** → 계산에서 제외 |

**절차**: 최소 지지도 설정 → 1개짜리 빈발 항목 → 2개짜리 조합 생성·검사 → 3개짜리 … → 빈발 항목집합에서 **최소 신뢰도** 이상인 규칙 생성

| 비교 | 아프리오리 | FP-Growth |
|---|---|---|
| 방식 | 후보 항목집합을 생성하며 데이터를 반복 스캔 | **FP-트리** 구조로 압축, 후보 생성 없음 |
| 속도 | 데이터가 크면 느림 | **빠름** (데이터 스캔 2번) |

```r
library(arules)
trans <- as(list_data, "transactions")
rules <- apriori(trans, parameter = list(support = 0.01, confidence = 0.5))
inspect(sort(rules, by = "lift")[1:5])     # 향상도 상위 5개 규칙
```

## 순차 패턴

연관분석에 **시간 순서**를 더한 것 — "A를 산 뒤 **일정 기간 후** B를 산다" (노트북 구매 → 한 달 뒤 마우스 구매)

> 순서를 알아야 하므로 **고객 식별 정보와 구매 시점** 데이터가 필요하다.

---

## 장단점

| 장점 | 단점 |
|---|---|
| 결과가 **"만약 ~ 이면"** 규칙이라 이해하기 쉬움 | 품목 수가 늘면 **계산량이 기하급수적**으로 증가 |
| 목표변수가 없는 비지도 분석 | 품목을 너무 세분화하면 **의미 없는 규칙**이 쏟아짐 → 상위 범주로 묶기 |
| 계산 원리가 간단 | **거래가 적은 품목**은 규칙 발견이 어려움 |

## 시험 포인트

| 주제 | 핵심 |
|---|---|
| 지지도 | P(A∩B) |
| 신뢰도 | P(A∩B) / P(A) |
| 향상도 | P(A∩B) / (P(A)·P(B)), 1이 기준 |
| 대칭성 | 지지도·향상도는 대칭, 신뢰도는 비대칭 |
| 아프리오리 | 최소 지지도, 비빈발 집합의 상위 집합 제외 |
| 순차 패턴 | 시간 순서, 고객 식별 정보 필요 |
