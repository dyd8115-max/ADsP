## 어떤 검정을 쓸까 ⭐

| 목적 | 종속변수 | 검정 | R 함수 |
|---|---|---|---|
| 한 집단 평균이 특정 값과 같은가 | 연속형 | **단일표본 t검정** | `t.test(x, mu = 값)` |
| 같은 대상의 전·후 비교 | 연속형 | **대응표본 t검정** | `t.test(x, y, paired = TRUE)` |
| 서로 다른 두 집단 평균 비교 | 연속형 | **독립표본 t검정** | `t.test(y ~ 그룹, var.equal = )` |
| 세 집단 이상 평균 비교 | 연속형 | **분산분석** | `aov(y ~ 그룹)` |
| 두 집단 분산 비교 | 연속형 | **F검정** | `var.test(x, y)` |
| 범주형 변수 두 개의 관련성 | 범주형 | **카이제곱 독립성 검정** | `chisq.test(표)` |
| 관측 빈도가 기대 분포를 따르는가 | 범주형 | **카이제곱 적합도 검정** | `chisq.test(x, p = 비율)` |

> 정규성을 만족하지 못하면 대응되는 **비모수 검정**(2-4 추정과 가설검정 참고)을 쓴다.

# t검정

## 가정

| 가정 | 확인 방법 |
|---|---|
| 정규성 | `shapiro.test()` — p > 0.05면 만족 |
| 독립성 | 표본이 서로 독립적으로 추출됨 |
| 등분산성 (독립표본만) | `var.test()` — p > 0.05면 등분산 |

> 등분산이 아니면 **웰치 t검정**을 쓴다. R의 `t.test()`는 기본값이 `var.equal = FALSE`라서 **웰치 t검정이 기본**이다.

## 종류별 핵심

| 검정 | 귀무가설 | 자유도 |
|---|---|---|
| 단일표본 | μ = μ₀ | n − 1 |
| 대응표본 | 전후 차이의 평균 = 0 | n − 1 (n = 쌍의 수) |
| 독립표본 (등분산) | μ₁ = μ₂ | n₁ + n₂ − 2 |

> **대응표본 t검정 = 차이값에 대한 단일표본 t검정**. 같은 사람의 다이어트 전후 몸무게처럼 짝이 있는 자료에 쓴다.

## 출력 해석

```r
t.test(extra ~ group, data = sleep)     # 수면제 두 종류의 수면시간 증가량 비교
```
```
	Welch Two Sample t-test

t = -1.8608, df = 17.776, p-value = 0.07939
alternative hypothesis: true difference in means between group 1 and group 2 is not equal to 0
95 percent confidence interval:
 -3.3654832  0.2054832
sample estimates:
mean in group 1 mean in group 2 
           0.75            2.33 
```

| 항목 | 해석 |
|---|---|
| p-value = 0.079 > 0.05 | 귀무가설 기각 못 함 → 두 그룹 평균 차이가 **유의하지 않음** |
| 신뢰구간 −3.37 ~ 0.21 | **0을 포함** → 차이가 없을 가능성을 배제 못 함 |
| df = 17.776 | 소수점 자유도 → **웰치 t검정**이라는 표시 |

> 같은 데이터를 **대응표본**으로 분석하면(같은 10명에게 두 약을 투여한 자료) t = −4.06, p = 0.0028 로 **유의**해진다. 짝을 고려하면 개인차가 제거되어 검정력이 높아지기 때문이다.

# 분산분석 ⭐

| 항목 | 내용 |
|---|---|
| 목적 | **세 집단 이상**의 평균이 같은지 검정 |
| t검정을 여러 번 하지 않는 이유 | 반복할수록 **제1종 오류가 누적**되어 커지기 때문 |
| 원리 | 전체 변동을 **집단 간 변동**과 **집단 내 변동**으로 나누어 비교 |
| 검정통계량 | **F = 집단 간 평균제곱 / 집단 내 평균제곱** — F가 클수록 집단 간 차이가 큼 |
| 귀무가설 | 모든 집단의 평균이 같다 |
| 대립가설 | **적어도 하나**의 집단 평균이 다르다 |

## 분산분석표 ⭐ (빈칸 채우기 단골)

k = 집단 수, N = 전체 관측치 수

| 요인 | 자유도 | 제곱합 | 평균제곱 | F |
|---|---|---|---|---|
| 처리 (집단 간) | **k − 1** | SSB | MSB = SSB / (k − 1) | **MSB / MSW** |
| 잔차 (집단 내) | **N − k** | SSW | MSW = SSW / (N − k) | |
| 합계 | **N − 1** | SST = SSB + SSW | | |

```r
summary(aov(Sepal.Length ~ Species, data = iris))
```
```
             Df Sum Sq Mean Sq F value Pr(>F)    
Species       2  63.21  31.606   119.3 <2e-16 ***
Residuals   147  38.96   0.265                   
```

| 확인 | 계산 |
|---|---|
| 처리 자유도 | 집단 3개 → 3 − 1 = **2** |
| 잔차 자유도 | 150 − 3 = **147** |
| 평균제곱 | 63.21 / 2 = 31.606, 38.96 / 147 = 0.265 |
| F | 31.606 / 0.265 ≈ **119.3** |
| 결론 | p < 0.05 → 품종별 꽃받침 길이 평균이 **모두 같지는 않다** |

## 사후검정

분산분석은 "어딘가 다르다"까지만 알려준다. **어느 집단끼리 다른지**는 사후검정으로 확인한다.

| 방법 | 특징 |
|---|---|
| 투키 HSD | 모든 쌍 비교, 가장 많이 사용 — `TukeyHSD(aov 결과)` |
| 셰페 | 보수적 |
| 던컨 | 덜 보수적 |
| 본페로니 | 유의수준을 비교 횟수로 나눠 보정 |

## 종류

| 구분 | 내용 |
|---|---|
| 일원배치 분산분석 | 요인 **1개** (예: 품종) |
| 이원배치 분산분석 | 요인 **2개** (예: 비료 종류 × 물 주는 양) — 두 요인의 **교호작용**도 검정 |

> **가정**: 정규성, 등분산성(`bartlett.test()`), 독립성

# 카이제곱 검정 ⭐

범주형 자료에서 **관측도수와 기대도수의 차이**를 검정한다.

```
         (관측도수 − 기대도수)²
χ² = Σ ─────────────────────────
               기대도수
```

| 종류 | 질문 | 자유도 |
|---|---|---|
| **적합도 검정** | 관측 분포가 이론 분포를 따르는가? (주사위가 공정한가?) | 범주 수 − 1 |
| **독립성 검정** | 두 범주형 변수가 서로 독립인가? (성별과 선호 음료) | (행 수 − 1) × (열 수 − 1) |
| **동질성 검정** | 여러 집단의 범주 비율이 같은가? | (행 수 − 1) × (열 수 − 1) |

## 기대도수 계산 ⭐

**기대도수 = 행 합계 × 열 합계 / 전체 합계**

```
            커피   차    합계
남성         30    20     50
여성         20    30     50
합계         50    50    100

남성·커피 기대도수 = 50 × 50 / 100 = 25   (네 칸 모두 25)
χ² = (30−25)²/25 + (20−25)²/25 + (20−25)²/25 + (30−25)²/25 = 4
자유도 = (2−1)(2−1) = 1
```

> 기대도수가 **5 미만인 칸이 20% 이상**이면 카이제곱 근사가 부정확 → **피셔의 정확 검정** (`fisher.test()`)

> 2×2 표에서 R `chisq.test()`는 기본으로 **연속성 보정**을 적용한다. 손계산과 값이 다르게 나오는 이유다.

# 시험 포인트

| 주제 | 핵심 |
|---|---|
| 대응표본 t검정 | 같은 대상 전·후 비교, `paired = TRUE` |
| 독립표본 t검정 | 먼저 등분산 확인(`var.test`), R 기본은 웰치 |
| 분산분석 | 세 집단 이상, F = MSB/MSW, 자유도 k−1 / N−k / N−1 |
| 분산분석 귀무가설 기각 | "**적어도 하나**가 다르다" → 사후검정 |
| 카이제곱 | 범주형, 독립성 자유도 (r−1)(c−1), 기대도수 = 행합×열합/전체 |
