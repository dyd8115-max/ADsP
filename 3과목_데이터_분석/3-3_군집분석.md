# 군집분석

> 3과목 데이터 분석 › 3장 정형 데이터 마이닝

---

## 군집분석이란

| 항목 | 내용 |
|---|---|
| 정의 | 정답 없이 **비슷한 개체끼리 묶는** 비지도 학습 |
| 목표 | 군집 **내부는 동질적**(거리 짧게), 군집 **사이는 이질적**(거리 멀게) |
| 활용 | 고객 세분화, 이상 탐지, 다른 분석의 전처리 |

| 구분 | 계층적 군집 | 비계층적 군집 |
|---|---|---|
| 방식 | 가까운 것끼리 **단계적으로 병합**(또는 분할) | 군집 수를 **미리 정하고** 개체를 배정 |
| 대표 | 최단·최장·평균·중심·와드 연결법 | **k-평균**, DBSCAN, 혼합분포, 자기조직화지도 |
| 군집 수 | 덴드로그램을 보고 나중에 결정 | 사전에 지정 (k-평균) |
| 재배정 | 한 번 병합되면 **이동 불가** | 반복하며 **이동 가능** |

## 거리 측도 ⭐⭐

### 연속형 변수

| 거리 | 공식 | 특징 |
|---|---|---|
| **유클리드** | √Σ(xᵢ − yᵢ)² | 가장 일반적인 직선 거리 |
| **맨해튼** | Σ\|xᵢ − yᵢ\| | 격자(블록) 거리 |
| **민코프스키** | (Σ\|xᵢ − yᵢ\|ᵐ)^(1/m) | m = 1이면 맨해튼, **m = 2면 유클리드** |
| **체비셰프** | max\|xᵢ − yᵢ\| | 차이가 가장 큰 좌표 하나 |
| 표준화 거리 | 각 변수를 표준편차로 나눈 뒤 유클리드 | 단위 차이 제거 |
| **마할라노비스** | 공분산(변수 간 상관)까지 고려 | 변수 간 상관이 있을 때 |

```
예) A(1, 2), B(4, 6)
유클리드 = √(3² + 4²) = 5
맨해튼   = 3 + 4 = 7
체비셰프 = max(3, 4) = 4
```

### 범주형 변수·기타

| 측도 | 설명 |
|---|---|
| **자카드 계수** | 두 집합의 **교집합 / 합집합** — 1에 가까울수록 유사, 자카드 거리 = 1 − 계수 |
| 단순 일치 계수 | 전체 속성 중 일치하는 속성의 비율 |
| **코사인 유사도** | 두 벡터의 **각도** 기준 — 문서·텍스트 유사도에 많이 사용 |

```
예) A = {사과, 배, 귤}, B = {배, 귤, 감, 포도}
자카드 계수 = |{배, 귤}| / |{사과, 배, 귤, 감, 포도}| = 2 / 5 = 0.4
```

# 계층적 군집 ⭐

| 방식 | 진행 |
|---|---|
| **병합형** | 각 개체가 하나의 군집에서 시작 → **가장 가까운 군집끼리 병합** 반복 |
| 분할형 | 전체 하나의 군집에서 시작 → 나눠 감 |

결과는 **덴드로그램**(나무 그림)으로 표현하고, 원하는 높이에서 잘라 군집 수를 정한다.

## 군집 간 거리 — 연결법 ⭐⭐

| 연결법 | 두 군집 사이 거리 | 특징 |
|---|---|---|
| **최단 연결법** | 가장 **가까운** 두 점의 거리 | 고립된 군집 발견에 유리, **사슬 모양**으로 길게 늘어지기 쉬움 |
| **최장 연결법** | 가장 **먼** 두 점의 거리 | 군집 내부 응집성 중시, 둥근 군집 |
| **평균 연결법** | 모든 점 쌍 거리의 **평균** | 이상값에 덜 민감 |
| **중심 연결법** | 두 군집 **중심 간** 거리 | 병합 후 새 중심은 **가중평균**으로 계산 |
| **와드 연결법** | 병합했을 때 **군집 내 오차제곱합의 증가량**이 최소인 쌍을 병합 | 비슷한 크기의 군집이 만들어짐 |

## 계산 예 ⭐

```
거리 행렬
     A    B    C    D
A    0
B    2    0
C    6    5    0
D   10    9    4    0

1단계: 가장 가까운 A–B(2) 병합 → (AB)

[최단 연결법]
d(AB, C) = min(6, 5)  = 5
d(AB, D) = min(10, 9) = 9
d(C, D)  = 4             ← 가장 작음 → 2단계: (CD) 병합
d(AB, CD) = min(6, 10, 5, 9) = 5

[최장 연결법]
d(AB, C) = max(6, 5)  = 6
d(AB, D) = max(10, 9) = 10
d(C, D)  = 4             ← 2단계: (CD) 병합
d(AB, CD) = max(6, 10, 5, 9) = 10
```

```r
d  <- dist(df, method = "euclidean")      # "manhattan", "maximum"(체비셰프), "minkowski"
hc <- hclust(d, method = "single")        # "complete", "average", "centroid", "ward.D2"
plot(hc)                                  # 덴드로그램
cutree(hc, k = 3)                         # 3개 군집으로 자르기
```

# 비계층적 군집 — k-평균 ⭐⭐

## 절차

1. 군집 수 **k**를 정하고 초기 중심 k개를 선택
2. 각 개체를 **가장 가까운 중심**의 군집에 배정
3. 군집별 **평균으로 중심을 다시 계산**
4. 중심이 더 이상 변하지 않을 때까지 2~3 반복

## 특징

| 장점 | 단점 |
|---|---|
| 알고리즘이 단순하고 **대용량 데이터에도 빠름** | **k를 미리 정해야** 함 |
| 한 번 배정된 개체도 반복 중 **다른 군집으로 이동 가능** | **초기 중심값에 따라 결과가 달라짐** → `nstart`로 여러 번 시도 |
| | 평균을 쓰므로 **이상값에 민감** → **k-메도이드**(실제 개체를 중심으로 사용)로 보완 |
| | 볼록한 **구형 군집**에 적합, 길쭉하거나 복잡한 모양은 잘 못 찾음 |
| | 평균 계산이 필요해 연속형 변수에 적합 |

## 군집 수 k 결정

| 방법 | 기준 |
|---|---|
| **엘보우 방법** | 군집 수를 늘려가며 **군집 내 제곱합**을 그렸을 때 감소가 **완만해지는 지점** |
| 실루엣 | 평균 실루엣 계수가 가장 큰 k |
| `NbClust` 패키지 | 여러 지표를 종합해 추천 |

```r
km <- kmeans(scale(df), centers = 3, nstart = 25)
km$cluster        # 각 개체의 군집
km$centers        # 군집 중심
km$withinss       # 군집별 내부 제곱합
```

> 거리 기반이므로 변수 단위가 다르면 **표준화**부터

# 그 밖의 군집 기법

| 기법 | 핵심 | 특징 |
|---|---|---|
| **DBSCAN** | **밀도 기반** — 반경 ε 안에 최소 개수 이상의 점이 있으면 군집으로 확장 | **임의 모양** 군집, **잡음(이상값) 구분**, 군집 수 지정 불필요 |
| **혼합분포 군집** | 데이터가 여러 **확률분포(주로 정규분포)의 혼합**에서 나왔다고 보고 모수를 추정 | **EM 알고리즘** 사용, 개체별 군집 소속 **확률** 제공, 이상값에 민감 |
| **자기조직화지도** | 인공신경망 기반, 고차원 데이터를 **2차원 격자**에 대응 | **입력층·경쟁층** 2개 층, **경쟁 학습**(승자 독식), 입력의 위상 보존, **역전파를 쓰지 않음** |

## EM 알고리즘

| 단계 | 내용 |
|---|---|
| E 단계 | 현재 모수로 각 개체가 각 군집에 속할 **확률(기댓값)** 계산 |
| M 단계 | 그 확률로 **모수(평균·분산·혼합 비율)를 다시 추정** |
| 반복 | 로그우도가 수렴할 때까지 |

> **자기조직화지도 vs 일반 신경망**: 일반 신경망은 역전파로 학습하지만, 자기조직화지도는 **한 번의 전방 계산**으로 승자 뉴런과 그 이웃의 가중치만 갱신 → 속도가 빠르다

## 군집 평가 ⭐

| 지표 | 계산 | 해석 |
|---|---|---|
| **실루엣 계수** | s = (b − a) / max(a, b) | **−1 ~ 1**, **1에 가까울수록** 잘 군집됨, 0 근처면 경계, 음수면 잘못 배정 |
| 던 지수 | 군집 간 최소 거리 / 군집 내 최대 거리 | **클수록** 좋음 |

> a = 같은 군집 내 다른 점들과의 평균 거리, b = 가장 가까운 다른 군집 점들과의 평균 거리

# 시험 포인트

| 주제 | 핵심 |
|---|---|
| 민코프스키 | m=1 맨해튼, m=2 유클리드 |
| 마할라노비스 | 변수 간 상관(공분산) 고려 |
| 자카드 | 교집합 / 합집합 |
| 최단 연결 | 가장 가까운 점, 사슬 모양 |
| 와드 연결 | 오차제곱합 증가량 최소 |
| 계층적 | 한 번 병합되면 이동 불가, 덴드로그램 |
| k-평균 | k 사전 지정, 초기값·이상값에 민감, 이동 가능 |
| DBSCAN | 밀도 기반, 임의 모양, 잡음 처리 |
| 혼합분포 | EM 알고리즘 |
| 자기조직화지도 | 경쟁 학습, 역전파 X, 2차원 격자 |
| 실루엣 | 1에 가까울수록 좋음 |
