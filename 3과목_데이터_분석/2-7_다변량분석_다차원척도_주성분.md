# 다차원척도법 ⭐

| 항목 | 내용 |
|---|---|
| 목적 | 개체 사이의 **유사성·비유사성(거리)**을 **2~3차원 공간의 점**으로 나타내 관계를 시각화 |
| 입력 | 개체 간 거리 행렬 |
| 적합도 | **스트레스 값** — 원래 거리와 그림 위 거리의 차이. **0에 가까울수록 적합** |

| 스트레스 값 (일반적 기준) | 적합 정도 |
|---|---|
| 0 | 완벽 |
| 0.05 이하 | 매우 좋음 |
| 0.05 ~ 0.10 | 만족 |
| 0.10 ~ 0.15 | 보통 |
| 0.15 이상 | 나쁨 |

## 종류

| 종류 | 데이터 | R 함수 |
|---|---|---|
| **계량적** 다차원척도법 | 구간·비율척도 (실제 거리) | `cmdscale()` |
| **비계량적** 다차원척도법 | **순서척도** (순위만 의미) | `isoMDS()`, `sammon()` — MASS 패키지 |

```r
loc <- cmdscale(eurodist, k = 2)     # 유럽 도시 간 거리 → 2차원 좌표
plot(loc, type = "n")
text(loc, labels = rownames(loc))
```

# 주성분분석 ⭐⭐

| 항목 | 내용 |
|---|---|
| 목적 | 상관관계가 있는 여러 변수를 **선형결합**해, 서로 **상관없는 소수의 주성분**으로 축약 |
| 원리 | 데이터의 **분산을 최대한 보존**하는 방향으로 새 축을 만듦 |
| 제1주성분 | 분산이 **가장 큰** 방향 — 제2주성분은 제1주성분과 **직교**하며 그다음으로 큰 분산 |
| 활용 | 차원 축소, **다중공선성 해결**(주성분 회귀), 시각화, 군집 전처리 |

## 공분산 행렬 vs 상관계수 행렬

| 사용 | 상황 |
|---|---|
| 공분산 행렬 | 변수들의 **단위가 같을 때** |
| 상관계수 행렬 | 변수들의 **단위·척도가 다를 때** — 표준화 효과 (`cor = TRUE`, `scale. = TRUE`) |

## 주성분 개수 선택 ⭐

| 방법 | 기준 |
|---|---|
| **누적 기여율** | 누적 분산 비율이 **70~90%** 이상이 되는 지점까지 (보통 80% 내외) |
| **스크리 그래프** | 고유값 그래프가 **완만해지기 직전**(팔꿈치)까지 |
| 고유값 기준 | 상관계수 행렬 사용 시 **고유값 1 이상**인 주성분 |

## R 출력 해석

```r
pca <- princomp(USArrests, cor = TRUE)
summary(pca)
```
```
Importance of components:
                          Comp.1    Comp.2    Comp.3     Comp.4
Standard deviation     1.5748783 0.9948694 0.5971291 0.41644938
Proportion of Variance 0.6200604 0.2474413 0.0891408 0.04335752
Cumulative Proportion  0.6200604 0.8675017 0.9566425 1.00000000
```

| 행 | 의미 |
|---|---|
| Standard deviation | 각 주성분의 표준편차 — 제곱하면 **고유값** (1.575² ≈ 2.48) |
| Proportion of Variance | 각 주성분이 설명하는 분산 비율 (고유값 / 변수 수) |
| Cumulative Proportion | 누적 기여율 |

> **해석**: 제2주성분까지 누적 기여율 **86.75%** → 변수 4개를 **주성분 2개**로 줄여도 정보 손실이 적다.

```r
loadings(pca)                     # 주성분 계수 — 각 변수의 가중치
screeplot(pca, type = "lines")    # 스크리 그래프
biplot(pca)                       # 개체와 변수를 한 그림에
```

| 주성분 | 계수 특징 (부호 무시) | 해석 |
|---|---|---|
| 제1주성분 | Murder 0.54, Assault 0.58, Rape 0.54, UrbanPop 0.28 — **범죄 변수 계수가 고르게 큼** | 전반적인 **강력범죄 수준** |
| 제2주성분 | UrbanPop 0.87이 압도적 | **도시화 정도** |

> 주성분 계수의 **부호는 함수나 소프트웨어에 따라 반대로 나올 수 있다**. 크기와 상대적 방향으로 해석한다.

## 요인분석과의 차이

| 구분 | 주성분분석 | 요인분석 |
|---|---|---|
| 목적 | 변수를 **축약** | 변수들 뒤의 **잠재 요인**을 찾음 |
| 방향 | 관측 변수 → 주성분 | 잠재 요인 → 관측 변수 |
| 결과 | 주성분 간 중요도 순서가 있음 (제1, 제2 …) | 요인 간 **대등한 관계** |

# 시험 포인트

| 주제 | 핵심 |
|---|---|
| 다차원척도법 | 거리 → 저차원 시각화, 스트레스 작을수록 좋음 |
| 계량 vs 비계량 | 구간·비율(`cmdscale`) vs 순서(`isoMDS`) |
| 주성분 | 분산 최대 보존, 서로 무상관(직교) |
| 단위가 다르면 | 상관계수 행렬 (`cor = TRUE`) |
| 주성분 개수 | 누적 기여율 80% 내외, 스크리 그래프 팔꿈치, 고유값 1 이상 |
| 표준편차의 제곱 | 고유값 |
