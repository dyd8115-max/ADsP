# 자료형 (Data Type)

## 1️⃣ 문자형 타입

| 타입 | 설명 |
|---|---|
| **character** | `' '` 또는 `" "`로 감싸 문자형을 표시 |

```r
x <- "hello"
y <- 'R언어'
class(x)    # "character"
```

---

## 2️⃣ 숫자형 타입

| 타입 | 크기 | 설명 |
|---|---|---|
| **numeric** | — | 정수형과 실수형을 묶는 **상위 개념** |
| **double** | **8 byte** | 실수형. **R의 기본 숫자 타입** |
| **integer** | **4 byte** | 정수형. 값 뒤에 `L`을 붙여 표시 |
| **complex** | **16 byte** | 복소수형. **실수(8byte) + 허수(8byte)** |

```r
typeof(1)      # "double"    ← 기본은 실수
typeof(1L)     # "integer"   ← L을 붙여야 정수
z <- 3 + 2i    # complex
```

**특수 숫자값**

| 값 | 설명 |
|---|---|
| **Inf** | 양의 무한대 |
| **-Inf** | 음의 무한대 |

---

## 3️⃣ 논리형 타입

| 타입 | 설명 |
|---|---|
| **logical** | `TRUE` / `FALSE` (대문자 표기, `T` / `F`로 축약 가능) |

---

## 4️⃣ 특수값 ⭐

| 값 | 정의 |
|---|---|
| **NaN** (Not a Number) | **수학적으로 정의되지 않은 연산 결과** (예: `0/0`) |
| **NA** (Not Available) | **값이 존재해야 하지만 누락된 상태** — 결측치 |
| **NULL** | **값 자체가 존재하지 않음** — 객체가 비어 있는 상태 |

```r
0/0           # NaN
c(1, NA, 3)   # 결측치 포함 벡터 (길이 3)
c(1, NULL, 3) # NULL은 사라짐 (길이 2)
```

> **구분 요령**: **NaN**은 "계산이 불가능", **NA**는 "있어야 할 값이 비었다", **NULL**은 "자리 자체가 없다"

---

## class() 와 typeof()

| 함수 | 정의 |
|---|---|
| **class()** | 객체가 **어떤 클래스로 취급되는지** 반환 |
| **typeof()** | 객체가 **메모리에 어떤 방식으로 저장되어 있는지** 반환 |

> **차이**: class는 **사용자 관점**, typeof는 **내부 저장 관점**

```r
x <- 1
class(x)    # "numeric"
typeof(x)   # "double"

f <- factor(c("A","B"))
class(f)    # "factor"
typeof(f)   # "integer"
```

# 연산자

## 1️⃣ 대입 연산자

| 방향 | 연산자 | 설명 |
|---|---|---|
| **오른쪽 → 왼쪽** | `=` , `<-` , `<<-` | 오른쪽 값을 왼쪽에 대입 |
| **왼쪽 → 오른쪽** | `->` , `->>` | 왼쪽 값을 오른쪽에 대입 |

```r
x <- 10        # 일반 할당 (권장)
10 -> y        # 반대 방향
x <<- 10       # 전역 할당
```

> **`<<-` / `->>`**: 함수 내부에서 **전역 변수**에 값을 대입할 때 사용

---

## 2️⃣ 산술 연산자

| 연산자 | 기능 | 예시 | 결과 |
|---|---|---|---|
| **`+`** | 덧셈 | `5 + 2` | `7` |
| **`-`** | 뺄셈 | `5 - 2` | `3` |
| **`*`** | 곱셈 | `5 * 2` | `10` |
| **`/`** | 나눗셈 | `5 / 2` | `2.5` |
| **`%%`** | 나머지 | `5 %% 2` | `1` |
| **`%/%`** | 몫 (정수 나눗셈) | `5 %/% 2` | `2` |
| **`^`** | 거듭제곱 | `5 ^ 2` | `25` |

> **주의**: 나머지는 `%%`, 몫은 `%/%`

---

## 3️⃣ 비교 연산자

| 연산자 | 기능 | 예시 | 결과 |
|---|---|---|---|
| **`==`** | 같다 | `5 == 5` | `TRUE` |
| **`!=`** | 같지 않다 | `5 != 5` | `FALSE` |
| **`>`** | 크다 | `5 > 2` | `TRUE` |
| **`<`** | 작다 | `5 < 2` | `FALSE` |
| **`>=`** | 크거나 같다 | `5 >= 5` | `TRUE` |
| **`<=`** | 작거나 같다 | `5 <= 2` | `FALSE` |

> **주의**: 할당은 `<-`, 비교는 `==`

---

## 4️⃣ 논리 연산자

| 연산자 | 기능 | 설명 |
|---|---|---|
| **`&`** | AND (벡터 전체) | 각 원소별로 비교 |
| **`&&`** | AND (단일 값) | 첫 번째 원소만 비교 |
| **`\|`** | OR (벡터 전체) | 각 원소별로 비교 |
| **`\|\|`** | OR (단일 값) | 첫 번째 원소만 비교 |
| **`!`** | NOT | 논리값을 반전 |

```r
TRUE & FALSE    # FALSE
TRUE | FALSE    # TRUE
!TRUE           # FALSE
```

# 판별 함수 (is 계열)

객체의 자료형이나 상태를 확인하여 **TRUE / FALSE**를 반환

## 1️⃣ 자료형 판별

| 함수 | 기능 | 예시 | 결과 |
|---|---|---|---|
| **`is.numeric()`** | 숫자형인가 | `is.numeric(10)` | `TRUE` |
| **`is.double()`** | 실수형인가 | `is.double(10)` | `TRUE` |
| **`is.integer()`** | 정수형인가 | `is.integer(10L)` | `TRUE` |
| **`is.character()`** | 문자형인가 | `is.character("a")` | `TRUE` |
| **`is.logical()`** | 논리형인가 | `is.logical(TRUE)` | `TRUE` |
| **`is.complex()`** | 복소수형인가 | `is.complex(3+2i)` | `TRUE` |

```r
is.numeric(10)     # TRUE
is.integer(10)     # FALSE  ← 그냥 10은 double
is.integer(10L)    # TRUE
```

---

## 2️⃣ 특수값 판별 ⭐

| 함수 | 기능 | 예시 | 결과 |
|---|---|---|---|
| **`is.na()`** | 결측치인가 | `is.na(NA)` | `TRUE` |
| **`is.nan()`** | 계산 불가값인가 | `is.nan(0/0)` | `TRUE` |
| **`is.null()`** | NULL인가 | `is.null(NULL)` | `TRUE` |
| **`is.finite()`** | 유한한 값인가 | `is.finite(10)` | `TRUE` |
| **`is.infinite()`** | 무한대인가 | `is.infinite(1/0)` | `TRUE` |

**주의할 관계** — NaN은 NA로도 판정된다.

```r
is.na(NaN)      # TRUE   ← NaN은 NA에 포함
is.nan(NA)      # FALSE  ← NA는 NaN이 아님
```

> **핵심**: `is.na()`는 **NA와 NaN을 모두** TRUE로 판정하지만, `is.nan()`은 **NaN만** TRUE로 판정

---

## 3️⃣ 자료구조 판별

| 함수 | 기능 |
|---|---|
| **`is.vector()`** | 벡터인가 |
| **`is.matrix()`** | 행렬인가 |
| **`is.array()`** | 배열인가 |
| **`is.list()`** | 리스트인가 |
| **`is.data.frame()`** | 데이터프레임인가 |
| **`is.factor()`** | 팩터인가 |

# 형 변환 함수 (as 계열)

자료형을 **강제로 바꾸는** 함수들

| 함수 | 기능 | 예시 | 결과 |
|---|---|---|---|
| **`as.numeric()`** | 숫자형으로 변환 | `as.numeric("10")` | `10` |
| **`as.integer()`** | 정수형으로 변환 | `as.integer(3.7)` | `3` (버림) |
| **`as.character()`** | 문자형으로 변환 | `as.character(10)` | `"10"` |
| **`as.logical()`** | 논리형으로 변환 | `as.logical(1)` | `TRUE` |
| **`as.factor()`** | 팩터로 변환 | `as.factor(c("A","B"))` | 레벨 A, B |

```r
as.numeric("abc")   # NA (경고 발생)
as.integer(3.9)     # 3   ← 반올림이 아니라 버림
as.logical(0)       # FALSE
as.logical(1)       # TRUE
```

> **주의**: `as.integer()`는 **반올림이 아니라 소수점 이하를 버린다.** 반올림은 `round()`를 씀

# 데이터 구조

R의 데이터 구조는 **차원**과 **저장 가능한 타입**에 따라 구분된다.

## 1️⃣ 벡터 (Vector)

| 항목 | 내용 |
|---|---|
| **정의** | **타입이 같은** 여러 데이터를 하나의 행으로 저장하는 **1차원** 데이터 구조 |
| **생성** | `c(변수1, 변수2, ...)` — combine의 약자 |
| **연속 값** | `c(1:6)` — **콜론(`:`)**을 사용해 시작값과 끝값 지정 가능 |

### 생성 예시

```r
v1 <- c(1, 2, 3, 4, 5)        # 숫자형 벡터
v2 <- c("A", "B", "C")        # 문자형 벡터
v3 <- c(TRUE, FALSE, TRUE)    # 논리형 벡터

v4 <- c(1:6)                  # 1 2 3 4 5 6
v5 <- 1:6                     # c() 없이도 가능
v6 <- c(1:3, 7:9)             # 1 2 3 7 8 9
```

### 원소 접근

```r
v <- c(10, 20, 30, 40, 50)

v[1]        # 10            ← 인덱스는 1부터 시작
v[c(1,3)]   # 10 30         ← 여러 개 동시 선택
v[-1]       # 20 30 40 50   ← 음수는 제외를 의미
v[v > 25]   # 30 40 50      ← 조건으로 선택
```

### 자동 형 변환 규칙 ⭐

벡터는 **한 가지 타입만** 담을 수 있으므로, 서로 다른 타입을 넣으면 자동으로 하나로 통일된다.

| 혼합 | 변환 결과 |
|---|---|
| **논리형 + 숫자형** | **숫자형**으로 변환 (`TRUE` → `1`, `FALSE` → `0`) |
| **논리형 + 문자형** | **문자형**으로 변환 |
| **숫자형 + 문자형** | **문자형**으로 변환 |

```r
c(TRUE, FALSE, 10)        # 1 0 10        → numeric
c(TRUE, "A")              # "TRUE" "A"    → character
c(1, "A")                 # "1" "A"       → character
```

> **우선순위**: **논리형 < 숫자형 < 문자형**. 항상 **더 포괄적인 타입**으로 변환된다.

---

## 2️⃣ 행렬 (Matrix)

| 항목 | 내용 |
|---|---|
| **정의** | **2차원 구조**를 가진 벡터 |
| **생성** | `matrix()` 함수 사용 |
| **행 지정** | `nrow` — 행(row)의 수를 결정 |
| **열 지정** | `ncol` — 열(column)의 수를 결정 |
| **저장 방향** | `byrow = T`를 지정하면 **열이 아닌 행 방향으로** 저장 (기본값은 열 방향) |

### nrow / ncol

```r
matrix(1:6, nrow = 2)
#      [,1] [,2] [,3]
# [1,]    1    3    5
# [2,]    2    4    6

matrix(1:6, ncol = 2)
#      [,1] [,2]
# [1,]    1    4
# [2,]    2    5
# [3,]    3    6
```

### byrow 옵션 ⭐

```r
matrix(1:6, nrow = 2)               # 기본값: byrow = FALSE
#      [,1] [,2] [,3]
# [1,]    1    3    5      ← 열 방향으로 채움 (↓)
# [2,]    2    4    6

matrix(1:6, nrow = 2, byrow = T)
#      [,1] [,2] [,3]
# [1,]    1    2    3      ← 행 방향으로 채움 (→)
# [2,]    4    5    6
```

> **핵심**: R의 기본 저장 방향은 **열(column)**이다. 행 방향으로 채우려면 반드시 `byrow = T`를 명시해야 한다.

### dim 함수로 변환

`dim()` 함수를 사용하면 **행의 개수와 열의 개수를 지정하여 벡터를 행렬로 변환**할 수 있다.

```r
v <- 1:6
dim(v) <- c(2, 3)      # 2행 3열로 변환
v
#      [,1] [,2] [,3]
# [1,]    1    3    5
# [2,]    2    4    6

dim(v)                 # 2 3   ← 차원 확인용으로도 사용
```

### 원소 접근

```r
m <- matrix(1:6, nrow = 2)

m[1, 2]     # 3     ← 1행 2열
m[1, ]      # 1 3 5 ← 1행 전체
m[, 2]      # 3 4   ← 2열 전체
```

> **표기 순서**: `[행, 열]`. 비워두면 전체를 의미한다.

## 3️⃣ 배열 (Array)

| 항목 | 내용 |
|---|---|
| **정의** | **3차원 이상**의 구조를 갖는 벡터 |
| **생성** | `array()` 함수에 `dim` 옵션으로 차원 지정 |

```r
array(1:12, dim = c(2, 3, 2))     # 2행 3열짜리 면이 2개

# , , 1
#      [,1] [,2] [,3]
# [1,]    1    3    5
# [2,]    2    4    6
#
# , , 2
#      [,1] [,2] [,3]
# [1,]    7    9   11
# [2,]    8   10   12
```

```r
a <- array(1:12, dim = c(2, 3, 2))
a[1, 2, 1]    # 3    ← 1번째 면의 1행 2열
a[, , 2]      # 2번째 면 전체
```

> **`dim = c(행, 열, 면)`** — 세 번째 값이 "층" 또는 "면"의 개수다.

---

## 4️⃣ 리스트 (List)

| 항목 | 내용 |
|---|---|
| **정의** | 데이터 타입, 구조에 상관없이 **사용자가 원하는 모든 것을 저장**할 수 있는 자료구조 |
| **특징** | 기존 벡터들과 달리 **성분 간에 이질적**인 특징을 가짐 |
| **생성** | `list()` 함수 사용 |

```r
l <- list(10, "A", TRUE, c(1,2,3))
# 각 원소가 서로 다른 타입 · 크기를 가져도 됨

l2 <- list(name = "홍길동", age = 25, scores = c(90, 85, 100))
# 이름을 붙여서 저장 가능
```

> **벡터와의 결정적 차이**: 벡터는 타입이 다르면 **자동 형 변환**이 일어나지만, 리스트는 **각 원소가 자기 타입을 그대로 유지**한다.

```r
c(1, "A", TRUE)       # "1" "A" "TRUE"   ← 전부 문자로 통일
list(1, "A", TRUE)    # 1 / "A" / TRUE   ← 각자 타입 유지
```

### 원소 접근 ⭐

```r
l <- list(name = "홍길동", age = 25, scores = c(90, 85, 100))

l[1]         # 리스트 반환 (껍데기 유지)
l[[1]]       # "홍길동"   ← 원소 자체 반환
l$name       # "홍길동"   ← 이름으로 접근
l$scores[2]  # 85
```

> **`[ ]` vs `[[ ]]`**: 대괄호 하나는 **리스트를 돌려주고**, 두 개는 **알맹이를 꺼낸다**.

### 중첩 가능

```r
l <- list(a = 1, b = list(x = 10, y = 20))
l$b$x        # 10
```

리스트 안에 리스트를 넣을 수 있어 **트리 형태의 복잡한 구조**도 표현 가능하다.

## 5️⃣ 데이터프레임 (Data Frame)

| 항목 | 내용 |
|---|---|
| **정의** | 데이터 분석을 위한 **2차원 구조**를 갖는 **관계형 데이터 구조** |
| **위상** | **R에서 가장 많이 활용되는** 데이터 구조 |
| **특징** | 행렬과 같은 모양을 갖지만, **여러 개의 벡터로 구성**되어 있기 때문에<br>**각 열은 서로 다른 타입의 데이터**를 가질 수 있음 |
| **생성** | `data.frame()` 함수 사용 |

```r
df <- data.frame(
  name = c("홍길동", "김철수", "이영희"),
  age = c(25, 30, 28),
  pass = c(TRUE, FALSE, TRUE)
)

df
#     name age  pass
# 1 홍길동  25  TRUE
# 2 김철수  30 FALSE
# 3 이영희  28  TRUE
```

> **열마다 타입이 달라도 되는 이유**: 데이터프레임은 내부적으로 **리스트 기반**이기 때문이다. 단, **각 열의 길이는 같아야** 한다.

## 6️⃣ 팩터 ⭐

| 항목 | 내용 |
|---|---|
| 정의 | **범주형 데이터**를 표현하는 구조 — 정해진 값(수준)만 가질 수 있음 |
| 수준 | `levels` — 범주의 목록. 기본은 **알파벳·가나다 순** 정렬 |
| 내부 저장 | 각 값을 **정수 코드**로 저장하고 코드에 수준 이름을 붙임 (`typeof`는 integer) |
| 순서형 | `ordered = TRUE` — 크기 비교가 가능한 순서척도 |

```r
f <- factor(c("중", "상", "하", "상"))
f
# [1] 중 상 하 상
# Levels: 상 중 하          ← 가나다 순 정렬

levels(f)      # "상" "중" "하"
nlevels(f)     # 3
table(f)       # 상 2 / 중 1 / 하 1

f2 <- factor(c("저", "고", "중"), levels = c("저", "중", "고"), ordered = TRUE)
f2 < "고"      # TRUE FALSE TRUE   ← 순서형이라 비교 가능
```

> **함정**: `as.numeric(factor(c("10", "5", "20")))`은 `10 5 20`이 아니라 **수준 코드** `1 3 2`를 돌려준다 (수준이 문자 순서로 "10" "20" "5"). 원래 숫자를 얻으려면 `as.numeric(as.character(f))`

| 구조 | 차원 | 타입 | 생성 함수 | 접근 |
|---|---|---|---|---|
| **벡터** | 1차원 | 단일 타입 | `c()` | `x[i]` |

## 인덱스 규칙 ⭐

**R의 벡터는 시작 인덱스 값을 1로 가진다.** (다른 언어가 `arr[0]`부터 시작하는 것과 대조되는 점)

```r
v <- c(10, 20, 30)
v[1]      # 10           ← 첫 번째 원소
v[0]      # numeric(0)   ← 에러가 아니라 빈 벡터
v[4]      # NA           ← 범위 밖은 NA
v[-1]     # 20 30        ← 음수는 제외
```

리스트, 데이터프레임, 행렬 **모두 1부터** 시작한다.

> **주의**: Java나 C처럼 인덱스 예외가 발생하지 않고 **조용히 빈 값 또는 NA**를 반환하므로 실수를 알아채기 어렵다.

# R 데이터 핸들링

## 1️⃣ 데이터 이름 변경

2차원 이상의 구조(행렬, 배열, 데이터프레임 등)는 **`colnames()`**와 **`rownames()`** 함수를 사용하여 행과 열의 이름을 **알 수 있으며 지정할 수도 있다.**

```r
m <- matrix(1:6, nrow = 2)

colnames(m)                          # NULL  ← 조회
colnames(m) <- c("A", "B", "C")      # 열 이름 지정
rownames(m) <- c("r1", "r2")         # 행 이름 지정

m
#    A B C
# r1 1 3 5
# r2 2 4 6
```

```r
names(df)                # 열 이름 (데이터프레임)
names(df)[2] <- "나이"   # 2번째 열만 이름 변경
```

| 함수 | 기능 |
|---|---|
| **`colnames(x)`** | 열 이름 조회 · 지정 |
| **`rownames(x)`** | 행 이름 조회 · 지정 |
| **`names(x)`** | 데이터프레임·리스트의 이름 조회 · 지정 |
| **`dimnames(x)`** | 행·열 이름을 리스트로 한번에 |

## 2️⃣ 데이터 추출

R이 보유한 여러 데이터 구조(**벡터, 행렬, 리스트, 데이터프레임**)는 모두 **인덱싱을 지원**하기 때문에 **대괄호 기호**를 사용하여 원하는 위치의 데이터를 얻을 수 있으며, **행과 열의 이름으로도** 데이터를 얻을 수 있다.

### 위치로 추출

```r
v[2]              # 벡터
m[1, 2]           # 행렬 — 1행 2열
m[1, ]            # 1행 전체
m[, 2]            # 2열 전체
df[1, 2]          # 데이터프레임 — 1행 2열
```

### 이름으로 추출

```r
m["r1", "B"]      # 행·열 이름으로 접근
df[, "age"]       # 열 이름으로 접근
df[1, "name"]     # 행 번호 + 열 이름 혼용
```

### `$` 기호 사용 ⭐

데이터프레임에서 **`$` 기호를 사용하여 원하는 열의 데이터**를 구할 수 있으며, **`$`와 `[ ]`를 혼용**할 수 있다.

```r
df$age                   # 25 30 28        ← 열 전체
df$age[1]                # 25              ← $ 와 [ ] 혼용
df$name[df$age > 26]     # "김철수" "이영희" ← 조건과 혼용

df[df$age > 26, ]        # 조건에 맞는 행 전체
df[df$age > 26, "name"]  # 조건에 맞는 행의 특정 열
```

> **`$`는 데이터프레임과 리스트에서만** 사용 가능하다. 벡터·행렬에는 쓸 수 없다.

## 3️⃣ 데이터 결합 ⭐

| 함수 | 기능 |
|---|---|
| **`rbind()`** | 데이터를 **행(row)으로 결합** — 위아래로 붙임 |
| **`cbind()`** | 데이터를 **열(column)로 결합** — 좌우로 붙임 |

### 결합 조건

**행렬과 행렬, 데이터프레임과 데이터프레임**의 경우, **행의 수 혹은 열의 수 둘 중 하나가 같을 경우** 결합이 가능하다.

| 함수 | 필요 조건 |
|---|---|
| **`rbind()`** | **열의 수**가 같아야 함 |
| **`cbind()`** | **행의 수**가 같아야 함 |

```r
df1 <- data.frame(name = "홍길동", age = 25)
df2 <- data.frame(name = "김철수", age = 30)

rbind(df1, df2)       # 행으로 결합 (2행이 됨)
#     name age
# 1 홍길동  25
# 2 김철수  30

cbind(df1, pass = TRUE)   # 열로 결합 (열이 추가됨)
#     name age pass
# 1 홍길동  25 TRUE
```

### 벡터 결합 — 재사용 규칙 ⭐

**벡터와 벡터의 결합**에서는 **재사용 규칙(Recycling Rule)**으로 인하여 **부족한 데이터를 앞에서부터 다시 재활용**하여 사용하며, **경고와 함께 결과를 반환**한다.

```r
a <- c(1, 2, 3, 4)
b <- c(10, 20)

rbind(a, b)
#   [,1] [,2] [,3] [,4]
# a    1    2    3    4
# b   10   20   10   20    ← 부족한 만큼 앞에서부터 재활용

c(1,2,3) + c(10,20)   # 11 22 13 (경고 발생)
#                       ← 3번째에서 10을 재사용
```

> **핵심**: 길이가 맞지 않아도 **에러가 아니라 경고**를 내고 실행된다. 배수 관계면 경고조차 없다.

# 제어문

## 1️⃣ 반복문

### for 문

```r
for (i in 1:5) {
  print(i)
}
# 1 2 3 4 5

for (name in c("A", "B", "C")) {   # 벡터를 직접 순회
  print(name)
}
```

> **자바와의 차이**: R의 `for`는 `for (변수 in 벡터)` 형태로, **파이썬의 for-each와 유사**하다. 조건식·증감식이 없다.

### while 문

```r
i <- 1
while (i <= 5) {
  print(i)
  i <- i + 1        # 증가를 직접 써줘야 함
}
```

### repeat 문

조건 없이 무한 반복하며, **`break`로만 탈출**한다.

```r
i <- 1
repeat {
  print(i)
  i <- i + 1
  if (i > 5) break
}
```

### 반복 제어

| 키워드 | 기능 |
|---|---|
| **`break`** | 반복문을 **완전히 종료** |
| **`next`** | 현재 회차를 건너뛰고 **다음 반복으로** (자바의 `continue`) |

```r
for (i in 1:5) {
  if (i == 3) next    # 3은 건너뜀
  if (i == 5) break   # 5에서 종료
  print(i)
}
# 1 2 4
```

## 2️⃣ 조건문

### if / else if / else

```r
score <- 85

if (score >= 90) {
  print("A")
} else if (score >= 80) {
  print("B")
} else {
  print("C")
}
# "B"
```

> **주의**: `else`는 반드시 **닫는 중괄호 `}`와 같은 줄**에 써야 한다. 줄을 바꾸면 에러가 난다.

### ifelse() — 벡터용 조건문

```r
x <- c(90, 75, 85)
ifelse(x >= 80, "합격", "불합격")
# "합격" "불합격" "합격"
```

> **`if`는 값 하나**, **`ifelse()`는 벡터 전체**에 적용된다. 데이터 분석에서는 `ifelse()`를 훨씬 많이 쓴다.

## 3️⃣ 사용자 정의 함수

| 항목 | 내용 |
|---|---|
| **정의 형식** | `함수명 <- function(인자) { 실행문 }` |
| **반환** | `return()`을 쓰거나, **마지막 줄의 값이 자동 반환** |

```r
# 기본 형태
add <- function(a, b) {
  return(a + b)
}
add(3, 5)        # 8

# return 생략 가능 (마지막 값이 반환됨)
add2 <- function(a, b) {
  a + b
}

# 기본값 지정
greet <- function(name, msg = "안녕하세요") {
  paste(msg, name)
}
greet("홍길동")              # "안녕하세요 홍길동"
greet("홍길동", "반갑다")     # "반갑다 홍길동"
```

> **`<<-`와의 연결**: 함수 내부에서 `<-`로 만든 변수는 함수 밖에 영향을 주지 않는다. 전역 변수를 바꾸려면 **`<<-`**를 써야 한다.

# 통계 분석에 자주 사용되는 R 함수

## 1️⃣ 숫자 연산

| 함수 | 기능 | 예시 | 결과 |
|---|---|---|---|
| **`abs(x)`** | 절댓값 | `abs(-5)` | `5` |

## 3️⃣ 벡터 연산

| 함수 | 기능 | 예시 | 결과 |
|---|---|---|---|
| **`seq(a, b, by)`** | 수열 생성 | `seq(1,10,by=2)` | `1 3 5 7 9` |
| **`seq(a, b, length.out)`** | 개수를 지정한 수열 | `seq(1,10,length.out=5)` | `1.00 3.25 5.50 7.75 10.00` |
| **`rep(x, times)`** | **통째로** 반복 | `rep(1:3, times=2)` | `1 2 3 1 2 3` |
| **`rep(x, each)`** | **원소별로** 반복 | `rep(1:3, each=2)` | `1 1 2 2 3 3` |
| **`length(x)`** | 원소 개수 | `length(c(1,2,3))` | `3` |
| **`sort(x)`** | 정렬 (**값** 반환) | `sort(c(3,1,2))` | `1 2 3` |
| **`order(x)`** | 정렬된 **인덱스** 반환 | `order(c(3,1,2))` | `2 3 1` |
| **`rev(x)`** | 역순 | `rev(1:3)` | `3 2 1` |
| **`unique(x)`** | 중복 제거 | `unique(c(1,1,2))` | `1 2` |
| **`which(조건)`** | 조건을 만족하는 **위치** | `which(c(5,10)>7)` | `2` |
| **`which.max(x)`** | 최댓값의 위치 | `which.max(c(1,9,3))` | `2` |
| **`prod(x)`** | 곱 | `prod(1:4)` | `24` |

> **`seq()` vs `1:10`**: 콜론은 1씩만 증가하지만, `seq()`는 **증가폭(`by`)과 개수(`length.out`)를 지정**할 수 있다.
> **`sort` vs `order`**: sort는 **정렬된 값**, order는 **정렬 순서의 인덱스**를 반환한다. 데이터프레임 정렬에는 `df[order(df$age), ]`처럼 order를 쓴다.

| **`rowSums(x)` / `colSums(x)`** | 행별 / 열별 합계 |

| **`apply(x, MARGIN, FUN)`** | 행 또는 열 단위로 함수 적용 |

**행렬 곱셈 구분** ⭐

```r

```

**apply의 MARGIN** ⭐

```r

apply(m, 2, sum)   # MARGIN=2 → 열 단위
```

> **암기**: **1 = 행(row), 2 = 열(column)**

## 7️⃣ 정규분포와 확률분포

R의 분포 함수는 **접두어 + 분포명** 구조를 갖는다.

| 접두어 | 의미 | 예시 (정규분포) |
|---|---|---|
| **`d`** | 확률밀도 (density) | `dnorm(0)` |
| **`p`** | 누적확률 (probability) | `pnorm(1.96)` → `0.975` |
| **`q`** | 분위수 (quantile) | `qnorm(0.975)` → `1.96` |
| **`r`** | 난수 (random) | `rnorm(10)` |

| 분포 | 함수명 |
|---|---|
| **정규분포** | `norm` |
| **균등분포** | `unif` |
| **이항분포** | `binom` |
| **포아송분포** | `pois` |
| **t분포** | `t` |
| **카이제곱분포** | `chisq` |
| **F분포** | `f` |

```r
rnorm(5, mean = 100, sd = 15)   # 평균 100, 표준편차 15인 난수 5개
runif(5)                        # 균등분포 난수 5개
pnorm(1.96)                     # 0.975   ← 표준정규분포 누적확률
qnorm(0.975)                    # 1.96    ← 97.5% 지점의 값
```

> **`p`와 `q`는 서로 역관계**다. `pnorm(qnorm(0.975))`는 `0.975`가 된다.
