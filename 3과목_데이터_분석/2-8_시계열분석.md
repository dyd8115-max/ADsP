# 시계열 분석

> 3과목 데이터 분석 › 2장 통계분석

---

## 시계열 자료와 정상성 ⭐

**시계열 자료**: 시간의 흐름에 따라 관측된 자료 (월별 매출, 일별 주가)

시계열 분석은 대부분 **정상성**을 가정한다. 비정상 시계열은 정상 시계열로 바꾼 뒤 분석한다.

### 정상성의 조건

| 조건 | 내용 |
|---|---|
| 평균 일정 | 모든 시점에서 평균이 같음 |
| 분산 일정 | 분산이 시점에 따라 변하지 않음 |
| 공분산 | 두 시점 간 공분산이 **시점이 아닌 시차에만** 의존 |

### 비정상 → 정상 변환 ⭐

| 문제 | 해결 |
|---|---|
| 평균이 일정하지 않음 (추세) | **차분** — 현 시점 값에서 이전 시점 값을 뺌 |
| 계절성 | **계절 차분** |
| 분산이 일정하지 않음 | **변환** — 로그 변환 등 |

| 용어 | 설명 |
|---|---|
| 백색잡음 | 평균 0, 분산 일정, **자기상관이 없는** 순수한 오차 |
| 자기상관함수 (ACF) | 시차 k만큼 떨어진 값들 사이의 상관 |
| 편자기상관함수 (PACF) | 중간 시점의 영향을 제거한, 시차 k 사이의 순수한 상관 |
| 단위근 검정 | 정상성 여부를 판단하는 검정 — ADF 검정 등 |

## 시계열 모형 ⭐⭐

| 모형 | 설명 |
|---|---|
| **자기회귀 모형 AR(p)** | 현재 값을 **과거 p개 시점의 값**으로 설명 |
| **이동평균 모형 MA(q)** | 현재 값을 **과거 q개 시점의 오차(백색잡음)**로 설명 — 항상 정상성 만족 |
| **ARMA(p, q)** | AR + MA |
| **ARIMA(p, d, q)** | **d번 차분**해 정상 시계열로 만든 뒤 ARMA(p, q) 적용 — 비정상 시계열용 |

### ACF·PACF로 모형 판별 ⭐

| 모형 | ACF | PACF |
|---|---|---|
| AR(p) | 점차 **감소** (지수적·사인 형태) | **p+1 시차부터 절단** (0에 가까워짐) |
| MA(q) | **q+1 시차부터 절단** | 점차 **감소** |
| ARMA | 점차 감소 | 점차 감소 |

> 암기: **AR은 PACF가 끊기고, MA는 ACF가 끊긴다**

### ARIMA 특수 형태

| 형태 | 의미 |
|---|---|
| d = 0 | ARMA(p, q) |
| p = 0 | IMA(d, q) |
| q = 0 | ARI(p, d) |

```
예) ARIMA(0, 1, 1)  →  1번 차분한 뒤 MA(1)  =  IMA(1, 1)
    ARIMA(1, 1, 0)  →  1번 차분한 뒤 AR(1)  =  ARI(1, 1)
```

## 분해 시계열 ⭐

시계열을 영향 요인별로 분리한다.

| 요인 | 설명 | 예 |
|---|---|---|
| **추세 요인** | 장기적으로 증가·감소하는 경향 | 인구 증가에 따른 소비 증가 |
| **계절 요인** | 요일·월·분기 등 **고정된 주기**로 반복 | 여름철 아이스크림 판매 |
| **순환 요인** | 고정되지 않은 **긴 주기**의 변동 | 경기 순환 |
| **불규칙 요인** | 위 요인으로 설명되지 않는 오차 | 우연한 사건 |

```r
decompose(ts_data)                          # 추세·계절·불규칙 분해
plot(stl(ts_data, s.window = "periodic"))
```

> 계절 요인 vs 순환 요인: **주기가 고정**이면 계절, **주기가 불규칙하고 길면** 순환

## 평활법

| 방법 | 설명 |
|---|---|
| 이동평균법 | 일정 기간의 평균으로 불규칙 변동을 줄이고 추세 파악 — 기간이 길수록 매끄러움 |
| 지수평활법 | **최근 관측치에 더 큰 가중치**를 주는 가중 이동평균. 평활상수 α(0~1)가 클수록 최근 값 반영↑ |

## R 함수

| 함수 | 기능 |
|---|---|
| `ts(x, frequency = 12, start = c(2020, 1))` | 시계열 객체 생성 (월별) |
| `diff(x, differences = 1)` | 차분 |
| `acf(x)` / `pacf(x)` | 자기상관·편자기상관 그래프 |
| `arima(x, order = c(p, d, q))` | ARIMA 적합 |
| `auto.arima(x)` (forecast) | 최적 ARIMA 자동 선택 |
| `forecast(model, h = 12)` (forecast) | 미래 h 시점 예측 |
| `HoltWinters(x)` | 지수평활 |

## 시험 포인트

| 주제 | 핵심 |
|---|---|
| 정상성 | 평균·분산 일정, 공분산은 시차에만 의존 |
| 평균이 비정상 | 차분 / 분산이 비정상 → 변환 |
| AR | PACF 절단, ACF 감소 |
| MA | ACF 절단, PACF 감소 |
| ARIMA(p,d,q) | d번 차분 후 ARMA |
| 분해 요인 | 추세·계절·순환·불규칙 |
