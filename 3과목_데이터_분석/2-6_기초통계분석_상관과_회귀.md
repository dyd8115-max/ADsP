# 상관분석

두 변수 사이 **선형 관계의 방향과 강도**를 확인한다. (공분산·상관계수의 정의는 2-3 기술통계량 참고)

## 상관계수의 종류

| 종류 | 대상 | 특징 |
|---|---|---|
| 피어슨 | 등간·비율척도 (연속형) | **선형** 관계, 정규성 가정 |
| 스피어만 | 순서척도, 또는 정규성 불만족 | **순위** 기반 비모수 |
| 켄달 타우 | 순서척도 | 순위 쌍의 일치 정도 |

## 해석 기준 (절댓값)

| 상관계수 크기 | 해석 |
|---|---|
| 0.7 이상 | 강한 상관 |
| 0.4 ~ 0.7 | 뚜렷한 상관 |
| 0.2 ~ 0.4 | 약한 상관 |
| 0.2 미만 | 거의 없음 |

> 기준은 교재마다 조금씩 다르다. 부호(방향)와 크기를 함께 읽으면 된다.

## R 실습

```r
data(mtcars)
cov(mtcars$mpg, mtcars$hp)                        # 공분산
cor(mtcars$mpg, mtcars$hp)                        # 피어슨: -0.776
cor(mtcars$mpg, mtcars$hp, method = "spearman")   # 스피어만: -0.895
cor(mtcars[, 1:4])                                # 상관계수 행렬
cor.test(mtcars$mpg, mtcars$hp)                   # 상관계수 유의성 검정
```
```
	Pearson's product-moment correlation

t = -6.7424, df = 30, p-value = 1.788e-07
alternative hypothesis: true correlation is not equal to 0
95 percent confidence interval:
 -0.8852686 -0.5860994
sample estimates:
       cor 
-0.7761684 
```

| 항목 | 해석 |
|---|---|
| 귀무가설 | 상관계수 = 0 (상관관계 없음) |
| p-value = 1.788e-07 | 0.05보다 훨씬 작음 → **상관관계 있음** |
| cor = −0.776 | **강한 음의 상관** — 마력이 클수록 연비가 낮음 |
| 신뢰구간 | 0을 포함하지 않음 → 유의 |
| df = 30 | **n − 2** = 32 − 2 |

# 회귀분석 ⭐⭐

**독립변수(설명변수)**가 **종속변수(반응변수)**에 미치는 영향을 선형식으로 모형화한다.

```
y = β₀ + β₁x₁ + β₂x₂ + ... + ε
```

| 구분 | 내용 |
|---|---|
| 단순 회귀 | 독립변수 1개 |
| 다중 회귀 | 독립변수 2개 이상 |
| 다항 회귀 | x², x³ 같은 고차항 포함 (계수에 대해서는 여전히 선형) |
| 추정 방법 | **최소제곱법** — 잔차 제곱합이 최소가 되는 회귀계수를 찾음 |

> 잔차 = 실제값 − 예측값

---

## 회귀모형의 가정 ⭐

| 가정 | 의미 | 확인 |
|---|---|---|
| **선형성** | 독립변수와 종속변수가 선형 관계 | 산점도, 잔차 대 적합값 그래프 |
| **독립성** | 잔차들이 서로 독립 | **더빈-왓슨 검정** (2에 가까우면 자기상관 없음) |
| **등분산성** | 잔차의 분산이 일정 | 잔차 그래프가 고르게 퍼져 있는지 |
| **비상관성** | 잔차끼리 상관이 없음 | 독립성과 함께 확인 |
| **정상성** | 잔차가 정규분포를 따름 | Q-Q 플롯, `shapiro.test(residuals(model))` |

> 암기: **선·독·등·비·정**

### 잔차 진단 그래프 — `plot(lm 결과)`

| 그래프 | 확인 |
|---|---|
| Residuals vs Fitted | **선형성**·등분산성 — 0을 중심으로 패턴 없이 퍼져야 함 |
| Normal Q-Q | **정규성** — 점들이 대각선 위에 있어야 함 |
| Scale-Location | **등분산성** — 수평선 주변에 고르게 |
| Residuals vs Leverage | **영향점** — 쿡의 거리 밖에 있는 점 확인 |

---

## 모형 검토 순서 ⭐

| 순서 | 질문 | 확인 위치 |
|---|---|---|
| 1 | 모형이 통계적으로 유의한가? | **F 통계량의 p-value** |
| 2 | 각 회귀계수가 유의한가? | 계수별 **t값의 p-value** (`Pr(>|t|)`) |
| 3 | 모형이 얼마나 설명하는가? | **결정계수** (다중회귀는 **수정된 결정계수**) |
| 4 | 데이터를 잘 적합하는가? | 잔차 그래프, 이상값·영향점 |
| 5 | 가정을 만족하는가? | 선형성·독립성·등분산성·정규성 |

---

## 결정계수와 분산분석표 ⭐

```
SST = SSR + SSE
(총 변동) = (회귀로 설명된 변동) + (설명되지 않은 잔차 변동)

결정계수 R² = SSR / SST = 1 − SSE / SST       (0 ≤ R² ≤ 1)
```

| 요인 | 자유도 | 제곱합 | 평균제곱 | F |
|---|---|---|---|---|
| 회귀 | **p** (독립변수 수) | SSR | MSR = SSR / p | **MSR / MSE** |
| 잔차 | **n − p − 1** | SSE | MSE = SSE / (n − p − 1) | |
| 합계 | **n − 1** | SST | | |

| 개념 | 설명 |
|---|---|
| 결정계수 | 종속변수 변동 중 회귀모형이 설명하는 비율 |
| 수정된 결정계수 | 변수를 추가하면 결정계수는 **무조건 증가**하므로, 변수 수를 고려해 보정한 값 — 다중회귀 비교에 사용 |
| 단순회귀에서 | 결정계수 = (상관계수)² |

```
예) SST = 100, SSE = 20  →  R² = 1 − 20/100 = 0.8
    n = 23, p = 2  →  MSE = 20 / 20 = 1,  MSR = 80 / 2 = 40,  F = 40 / 1 = 40
```

## R 출력 해석 ⭐⭐

```r
model <- lm(mpg ~ wt + hp, data = mtcars)
summary(model)
```
```
Coefficients:
            Estimate Std. Error t value Pr(>|t|)    
(Intercept) 37.22727    1.59879  23.285  < 2e-16 ***
wt          -3.87783    0.63273  -6.129 1.12e-06 ***
hp          -0.03177    0.00903  -3.519  0.00145 ** 
---
Residual standard error: 2.593 on 29 degrees of freedom
Multiple R-squared:  0.8268,	Adjusted R-squared:  0.8148 
F-statistic: 69.21 on 2 and 29 DF,  p-value: 9.109e-12
```

| 읽을 곳 | 해석 |
|---|---|
| 회귀식 | **mpg = 37.23 − 3.88 × wt − 0.032 × hp** |
| wt 계수 −3.88 | hp가 같을 때 무게가 1(천 파운드) 늘면 연비가 **3.88 감소** |
| t value | **Estimate ÷ Std. Error** → −3.87783 / 0.63273 ≈ −6.129 |
| Pr(>\|t\|) | 모든 계수 p < 0.05 → wt, hp 모두 **유의** |
| 잔차 자유도 29 | n − p − 1 = 32 − 2 − 1 → 관측치 **n = 32** |
| R² = 0.8268 | 연비 변동의 약 **82.7%**를 설명 |
| 수정된 R² = 0.8148 | 변수 수를 보정한 설명력 |
| F = 69.21, p = 9.1e-12 | 모형 전체가 **유의** |
| Residual standard error | 잔차의 표준편차 추정치 = √MSE |

> **계산형 문제**: 출력에서 값을 역산하는 문제가 자주 나온다.
> - t = 추정치 / 표준오차
> - 관측치 수 = 잔차 자유도 + 독립변수 수 + 1
> - F의 자유도 = (p, n − p − 1)

## 변수 선택법 ⭐

| 방법 | 진행 |
|---|---|
| **전진 선택법** | 상수항만 있는 모형에서 시작해 **중요한 변수를 하나씩 추가** |
| **후진 제거법** | 모든 변수를 넣고 시작해 **덜 중요한 변수를 하나씩 제거** |
| **단계적 선택법** | 변수를 추가하면서, 매 단계 **기존 변수의 제거 여부도 재검토** |

| 평가 기준 | 해석 |
|---|---|
| AIC | 작을수록 좋은 모형 |
| BIC | 작을수록 좋음, 변수 수에 AIC보다 **더 큰 벌점** |
| 멜로우즈 Cp | 작고, 모수 개수(변수 수 + 1)에 가까울수록 좋음 |

```r
step(lm(y ~ 1, data = df), scope = ~ x1 + x2 + x3, direction = "forward")   # 전진
step(lm(y ~ ., data = df), direction = "backward")                           # 후진
step(lm(y ~ ., data = df), direction = "both")                               # 단계적
```

> `step()` 출력에서는 각 단계 **AIC가 줄어드는 방향**으로 변수가 추가·제거된다.

## 정규화 선형회귀

회귀계수 크기에 **벌점**을 주어 과적합과 다중공선성을 줄인다. 벌점 강도는 λ로 조절 — λ가 클수록 계수가 더 작아진다.

| 방법 | 벌점 | 특징 |
|---|---|---|
| **릿지** | 계수 **제곱합** (L2) | 계수를 0에 **가깝게** 줄임 — 0이 되지는 않음 |
| **라쏘** | 계수 **절댓값 합** (L1) | 일부 계수를 **정확히 0**으로 → **변수 선택 효과** |
| **엘라스틱넷** | L1 + L2 | 둘의 절충 |

> "변수 선택 기능이 있는 정규화 회귀" = **라쏘**

## 범주형 독립변수 — 더미 변수

범주가 k개면 **k − 1개**의 더미 변수(0/1)를 만든다. 남은 1개 범주가 기준이 된다.

```
혈액형 A, B, O, AB → 더미 3개 (기준: A)
B형 (1, 0, 0) / O형 (0, 1, 0) / AB형 (0, 0, 1) / A형 (0, 0, 0)
```

# 로지스틱 회귀분석 ⭐

종속변수가 **범주형(주로 0/1)**일 때, 해당 범주에 속할 **확률**을 예측하는 회귀분석

| 항목 | 내용 |
|---|---|
| 선형회귀를 못 쓰는 이유 | 선형식은 −∞ ~ +∞ 값을 내므로 확률(0~1)로 쓸 수 없음 |
| 변환 | **시그모이드 함수**로 0~1 사이 확률로 변환 |
| 오즈 | 성공 확률 / 실패 확률 = **p / (1 − p)** |
| 로짓 | **log(오즈)** — 이것을 독립변수의 선형식으로 표현 |
| 추정 방법 | **최대우도법** |
| 모형 검정 | **카이제곱 검정** (이탈도 비교) |
| 분류 | 예측 확률이 기준값(보통 0.5)보다 크면 1 |

```
log( p / (1 − p) ) = β₀ + β₁x₁ + β₂x₂ + ...
```

## 계수 해석 ⭐

| 표현 | 의미 |
|---|---|
| β₁ | x₁이 1 증가할 때 **로그 오즈**가 β₁만큼 증가 |
| **exp(β₁)** | x₁이 1 증가할 때 **오즈가 exp(β₁)배** — 오즈비 |

```
예) β₁ = 0.693  →  exp(0.693) ≈ 2  →  x₁이 1 늘면 성공 오즈가 약 2배
```

## R 코드

```r
model <- glm(y ~ x1 + x2, data = df, family = binomial)   # binomial → 로지스틱
summary(model)
exp(coef(model))                                       # 오즈비
predict(model, newdata = test, type = "response")      # 확률로 예측
```

| 옵션 | 의미 |
|---|---|
| `glm` | 일반화 선형모형 |
| `family = binomial` | **로지스틱 회귀** |
| `family = poisson` | 포아송 회귀 (횟수 자료) |
| `type = "response"` | 로짓이 아닌 **확률**로 출력 |

## 선형회귀 vs 로지스틱 회귀

| 구분 | 선형회귀 | 로지스틱 회귀 |
|---|---|---|
| 종속변수 | 연속형 | 범주형 |
| 추정 | 최소제곱법 | **최대우도법** |
| 모형 검정 | F검정 | **카이제곱 검정** |
| 계수 검정 | t검정 | z검정 (왈드 검정) |
| 결과 | 값 예측 | 확률 예측 → 분류 |

# 시험 포인트

| 주제 | 핵심 |
|---|---|
| 상관분석 자유도 | n − 2 |
| 회귀 가정 | 선형성·독립성·등분산성·비상관성·정상성 |
| 더빈-왓슨 | 잔차 독립성(자기상관) 검정, 2에 가까우면 좋음 |
| 모형 유의성 | F검정 p-value |
| 계수 유의성 | t검정 p-value, t = 추정치 / 표준오차 |
| 결정계수 | SSR/SST, 변수 추가 시 항상 증가 → 수정된 결정계수 |
| 잔차 자유도 | n − p − 1 |
| 변수 선택 | 전진·후진·단계적, AIC 작을수록 좋음 |
| 다중공선성 | VIF 10 이상 |
| 라쏘 | L1, 계수를 0으로 → 변수 선택 |
| 로지스틱 | 최대우도법, exp(β) = 오즈비, `family = binomial` |
